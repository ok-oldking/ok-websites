OK-AzurPromilia 專案文件

面向《藍色星原：旅謠》（Azur Promilia）的遊戲自動化專案，基於 ok-script 開發。

功能概覽

專案已接入實機自動化支援，涵蓋日常流程、小遊戲玩法接管與輔助功能：

  • 一次性日常任務 (src/tasks/onetime/)：
    • 一鍵日常 (DailyTask)：多子任務編排與狀態追蹤，一鍵執行完整日常。
    • 家園日常 (HomeDailyTask)：支援家園烹飪製作、牧場作物收穫等家園流程。
    • 每日委託 (CommissionDailyTask)：日常委託接取與提交。
    • 每日收菜 (ClaimDailyTask)：自動領取每日活躍、周常活躍、戰令與大月卡獎勵。
  • 觸發式玩法與小遊戲 (src/tasks/trigger/)：
    • 自動祖贊卡之梯 (AutoJengaTask)：根據八字擺動軌跡擬合與碰撞面積判定，實現全自動高分放置。
    • 自動花瓣音遊 (AutoRhythmTask)：高精度滾動速度擬合與輸入時序預測，支援多軌、長按與雙鍵連擊。
    • 自動跳過劇情 (SkipDialogTask)：基於中央文本帶特徵的快速跳過與確認。
    • 星結契約輔助 (StarLinkAssistTask)：螢幕中心準心光圈圓弧擬合與自動命中。
    • 寶箱開鎖輔助 (TreasureUnlockTask)：高精度顏色帶連通域檢測與自動對齊開鎖。

開發與測試

本專案依賴通過 uv 管理，支援 Python 3.12：

# 安装/同步依赖
uv sync

# 运行 Debug 模式
uv run python main_debug.py

# 执行全量单元测试
uv run python -m unittest discover -s tests
# 或使用 PowerShell 逐文件运行测试
./run_tests.ps1
