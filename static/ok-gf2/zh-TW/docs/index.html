ok-gf2

基於影像識別的少前2（Girls' Frontline 2）自動化程式，部分功能支援後臺執行，基於 ok-script 開發。
An image-recognition-based automation tool for Girls' Frontline 2, with background mode support, developed with ok-script.

通過模擬 Windows 使用者介面進行操作，無記憶體讀取、無檔案修改

執行要求與推薦設定

  • 系統：Windows
  • 遊戲：直接使用 PC 版少前2，可原生後臺執行
  • 解析度：支援所有 16:9 解析度
  • 幀率：推薦 120 FPS，幀率越高越好
  • 語言：支援簡體中文 / 英文（英文可能有不少問題）
  • 顯示：Windows 自動 HDR 必須關閉，可以使用 RTX HDR
  • 背景：主頁背景需要使用暗色，不能用白色背景，不然識別不到文字
  • 執行許可權：建議管理員許可權執行（原始碼模式必須）
  • 路徑：安裝/執行路徑儘量使用純英文

⚙️ 部分引數說明

1. 當前物資關卡名稱

  • 若為 小活動，物資關卡會顯示為 物資模式，此時無需填寫任何內容。
  • 若為 大活動，物資關卡會顯示為 鑄碑者的黎明·上篇，則需要填寫物資關卡名為 鑄碑者的黎明。

⚠️ 不正確填寫可能會影響活動代理邏輯。

2. 已確認啟用遊戲內全域性自動功能

路徑：設定 → 其他 → 自動戰鬥設定

3. 喝水

邏輯：進入活動層後先按 A 後按 W 再按 D，需自行調整。 使用格式：{A按住秒数}-{W按住秒数}-{D按住秒数} 預設值及示例：1.087-1.0-0.8（已初步驗證）。如果移動時被擋住，請在「喝水」配置中逐個微調按鍵時長；已儲存的配置不會自動覆蓋。

4. 吃飯

邏輯：進入活動層後先按 S 後點按 D，需自行調整。 使用格式：{S按住秒数} 示例：1.3

💻 開發者專區

從原始碼執行 (Python)

本專案僅支援 Python 3.12 版本，需以管理員許可權啟動 CMD / PyCharm / VSCode。

# 如果首次 clone 未带子模块参数，请先执行
git submodule update --init --recursive

# CPU 版本，使用 OpenVINO
pip install -r requirements.txt --upgrade

# 运行 Release 版本
python main.py

# 运行 Debug 版本
python main_debug.py

# CUDA 版本，使用 paddle-gpu 加速，推荐 N 卡 30 系以上使用，速度飞快
pip install -r requirements-dml.txt --upgrade

# 运行 Release 版本
python main_direct_ml.py

# 运行 Debug 版本
python main_direct_ml_debug.py

命令列引數

您可以通過命令列引數實現自動化啟動。

# 启动后自动执行第1个任务，并在任务完成后退出程序
ok-gf2.exe -t 1 -e
  • -t 或 --task：啟動後自動執行第 N 個任務。
  • -e 或 --exit：任務執行完畢後自動退出程式。
