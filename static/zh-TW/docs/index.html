Vibe Coding 自動化框架

在 Codex、Claude Code 或任何支援 MCP 的程式設計代理裡許個願，得到一個可部署的自動化程式。

代理通過 MCP 觀察 Windows 應用、遊戲或安卓裝置，編寫 Python 任務，在真實目標上執行並修復失敗。ok-script 把完成的任務連同桌面 GUI 打包成可分發的 Windows 安裝包。打包後的程式獨立執行，無需代理保持連線。

MCP 開發流程

代理用自己的工具編輯檔案、讀取日誌；MCP 讓它直接操作正在執行的應用。

  • :material-book-open-variant:{ .lg .middle } 1. 學習

    list_skills 和 get_skill 返回當前安裝版本自帶的開發、模板、測試和過載流程；代理從已安裝包中讀取準確的 Python 簽名。

  • :material-monitor-screenshot:{ .lg .middle } 2. 觀察

    screenshot 儲存已配置視窗或裝置的當前畫面，代理看到的就是任務將要看到的。

  • :material-play-circle:{ .lg .middle } 3. 執行

    run_task 在真實目標上執行 Python 任務檔案。每次嘗試先恢復並驗證起始狀態，再由 run() 執行並斷言自動化結果。

  • :material-file-search:{ .lg .middle } 4. 檢查

    每次嘗試在 logs/mcp/<run_id>/ 下寫入 run.log、status.json 和任務截圖。get_run_status 報告進度和錯誤，stop_task 用於取消。

  • :material-wrench:{ .lg .middle } 5. 修復

    list_tasks 返回已註冊任務的原始碼路徑；修改後用 reload_tasks 在執行中的程序裡替換。無法重置時用 exit_process 結束執行時。

  • :material-rocket-launch:{ .lg .middle } 6. 交付

    註冊任務，通過 GUI 或 python -m ok run_task 執行，並用 PyAppify 打包成 Windows 安裝包。詳見打包與釋出。

可以這樣告訴程式設計代理

=== "開發任務"

> 連線這個專案的 ok-script MCP 服務，讀取開發技能。檢查已安裝的截圖、匹配和輸入 API，給出準確簽名和原始碼位置。開發可複用 Python 任務：開啟設定、啟用“顯示詳情”、儲存並驗證結果。每次嘗試前恢復並驗證起始介面，測試重複執行，程式碼儲存到專案中。使用 ok-script API 和 MCP，不使用 Computer Use 工具。最後給出不依賴代理或大模型呼叫的準確執行命令。

=== "修復任務"

> 連線這個專案的 ok-script MCP 服務，讀取 reload-tasks 技能。用 list_tasks 找到出錯任務的原始碼，修改該檔案，按任務 ID 過載並等待過載成功。恢復並驗證起始介面，重複執行已註冊的實現，並給出執行日誌和截圖中的證據。

=== "安裝環境"

> 在當前專案中安裝 ok-script 並配置執行環境。先讀取 https://raw.githubusercontent.com/ok-oldking/ok-script/master/docs/agent-setup.md ，按照其中的安裝技能操作，保留專案現有的依賴約束。

程式設計代理提示詞提供了查詢 API、開發任務和維護已有任務的完整示例。

三步連線

.\.venv\Scripts\python.exe -m pip install "ok-script[default]"
.\.venv\Scripts\python.exe -m ok mcp --config src.config:config
  1. 用專案配置啟動執行時，或在已有桌面應用中開啟 設定 > 基本設定 > 啟用 MCP 伺服器。
  2. 從有效的 logs/mcp/connections/<pid>-<port>.json 記錄中讀取 URL 和 token。
  3. 讓代理的 MCP 客戶端通過 Streamable HTTP 連線，並使用 Authorization: Bearer <token> 請求頭。

!!! warning "本地開發者許可權" 服務只監聽本機迴環地址，但已連線的代理可以用你的賬戶許可權執行 Python。不要公開 token，日常使用請保留單獨的、關閉 MCP 的啟動器。
