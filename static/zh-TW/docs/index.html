ok-script：開發時用 Token，自動化指令碼反覆用

English · 專案主頁

把需求交給程式設計代理，通過 MCP 連線 ok-script，讓代理觀察目標應用、編寫 Python 指令碼、執行驗證並修復問題。完成後儲存指令碼，今後直接重複執行。

把 Token 花在開發上，讓生成的 Python 自動化獨立執行。 開發可能需要多輪驗證，應用更新後也可能需要再次修改。使用本地識別與輸入的指令碼在日常執行時無需呼叫大模型，也不消耗模型 Token。

從 MCP 開始

  1. 在支援 MCP 和本地檔案、程序訪問的程式設計代理中開啟你的自動化專案目錄。
  2. 按快速開始安裝執行環境並連線本地 MCP 服務。
  3. 描述目標應用、起始狀態、操作步驟和可觀察的成功條件。
  4. 讓代理讀取技能、檢查已安裝的 API、編寫 Python，並通過 MCP 實測。
  5. 通過應用 GUI 或命令列執行儲存的任務，無需保持代理連線。

可以這樣提需求

連線這個專案的 ok-script MCP 服務。讀取 develop 技能，檢查已安裝版本中本任務需要的截圖、模板匹配和輸入 API，先給出核實過的簽名及原始碼位置。然後實現一個可複用的 Python 任務：開啟設定、啟用我指定的選項、儲存，並驗證該選項保持開啟。每次嘗試前恢復並驗證起始介面。只用 ok-script 截圖和互動，不使用 Computer Use 工具。把任務儲存到專案中，並告訴我如何脫離代理執行。

程式設計代理提示詞提供了查詢 API、開發任務和維護已有任務的完整示例。
