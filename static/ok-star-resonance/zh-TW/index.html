常見問題

提交問題前，請依次檢查以下專案：

  1. 客戶端語言：非中文客戶端需要在應用設定中指定正確的遊戲語言。
  2. 採集識別：採集依賴 OCR。調整視角，避免任務引導遮擋採集按鈕。
  3. 解壓目錄：將程式解壓到只包含英文字元的目錄。
  4. 防毒軟體：將下載目錄與安裝目錄加入防毒軟體和 Windows Defender 的白名單。
  5. 顯示設定：使用 16:9 解析度和預設亮度，關閉顯示卡濾鏡、銳化及 FPS 疊加層。
  6. 按鍵繫結：在應用中同步遊戲內的自定義按鍵；設定頁未列出的按鍵不受支援。
  7. 軟體版本：確認正在使用最新版本的 ok-star-resonance。
  8. 副本移動錯誤：切換抓包目標網絡卡，或使用 WinDivert 抓包。
  9. 仍未解決：提交 Issue，並附上錯誤發生時的螢幕截圖和指令碼日誌。

提交問題時請提供

  • ok-star-resonance 版本與遊戲客戶端語言
  • Windows 版本、遊戲解析度和顯示縮放比例
  • 觸發問題的任務及復現步驟
  • 錯誤發生時的截圖與相關日誌
  • 使用 Npcap 還是 WinDivert（如果任務依賴抓包）

請勿上傳真實使用者抓包、賬號資料或其他敏感資訊。
