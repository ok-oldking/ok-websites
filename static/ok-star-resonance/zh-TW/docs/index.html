ok-star-resonance

基於影像識別與網路抓包的《星痕共鳴》Windows 桌面自動化工具。

開始使用{ .md-button .md-button--primary } 檢視原始碼{ .md-button }

!!! warning "免責宣告"

本軟體僅通過現有使用者介面與遊戲互動，不讀取遊戲記憶體，也不修改或注入遊戲檔案及程序。軟體開源、免費，僅供個人學習交流使用，不得用於商業或營利活動。使用本軟體產生的風險與後果由使用者自行承擔。

能做什麼

自動化任務

釣魚、採集、領取月卡、技能連點、組隊確認、協會狩獵、單人副本等。

多語言識別

根據功能提供簡體中文、繁體中文、英文及日文客戶端支援。

MIDI 與教學譜面

支援 MIDI 演奏、視覺化，以及遊戲內教學譜面的自動演奏。

執行要求

  • Windows 作業系統與前臺執行的遊戲視窗
  • 16:9 遊戲解析度，最低 1280×720
  • 使用原始碼執行時僅支援 Python 3.12
  • 部分任務需要 Npcap 或 WinDivert 提供網路包捕獲能力
