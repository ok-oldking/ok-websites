從原始碼執行

本專案僅支援 Windows 與 Python 3.12。建議使用 uv 管理本地虛擬環境。

準備環境

git clone https://github.com/Sanheiii/ok-star-resonance.git
cd ok-star-resonance
uv venv --python 3.12
uv pip sync requirements.txt

啟動程式

# 开发模式：开启调试日志和截图
.\.venv\Scripts\python.exe main_debug.py

# 发布模式
.\.venv\Scripts\python.exe main.py

執行測試

# 运行仓库中的全部 unittest 文件
.\run_tests.ps1

# 运行不依赖真实游戏窗口的单个测试
.\.venv\Scripts\python.exe -m unittest tests.test_packet_parser

tests/TestMain.py 依賴測試截圖和 ok.test.TaskTestCase，缺少 tests/images/test.png 時不能作為可靠的無頭測試。

構建文件網站

文件依賴與應用依賴分開管理：

.\.venv\Scripts\python.exe -m pip install -r requirements-docs.txt
.\.venv\Scripts\python.exe -m mkdocs serve

瀏覽器訪問終端顯示的本地地址即可預覽。生成靜態 HTML：

.\.venv\Scripts\python.exe -m mkdocs build --strict

生成結果位於 site/，可部署到 GitHub Pages 或任意靜態網站託管服務。
