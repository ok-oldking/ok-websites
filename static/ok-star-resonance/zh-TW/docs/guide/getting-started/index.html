安裝與啟動

  1. 從上述渠道下載最新版本並解壓或安裝。
  2. 如果防毒軟體攔截程式，將下載目錄和安裝目錄加入信任區。
  3. 啟動《星痕共鳴》，使用 16:9 解析度，最低 1280×720。
  4. 啟動 ok-star-resonance，並在設定中選擇正確的客戶端語言。
  5. 保持遊戲視窗位於前臺，然後選擇需要執行的任務。

可選內容

需要修改內建識別模板時，可以將模板倉庫克隆到專案根目錄的 ok_templates：

git clone https://github.com/Sanheiii/ok-star-resonance-templates.git ok_templates

ok_templates 和 midi 都屬於可選的本地內容，預設不會提交到 Git。

使用前檢查

  • 關閉顯示卡濾鏡、銳化與遊戲畫面上的 FPS 疊加層。
  • 遊戲內使用自定義按鍵時，在應用設定中同步配置受支援的按鍵。
  • 依賴抓包位置資料的任務需要選擇正確的網絡卡，或改用 WinDivert。
  • 本工具不支援後臺執行，請勿遮擋或最小化遊戲視窗。
