特性

  • 支援任意 16:9 解析度，視窗化和全屏均可，最低 1280×720。
  • 支援基於 PushDeer 的狀態通知，配置方法見 PushDeer 官方說明。
  • 支援使用者自定義指令碼。
  • 通過螢幕捕獲、OCR、模板匹配、目標檢測與網路包捕獲感知遊戲狀態。
  • 通過 Windows 介面模擬鍵盤和滑鼠操作，不讀取遊戲記憶體，不修改遊戲檔案，不注入遊戲程序。
執行方式

遊戲視窗必須保持在前臺；當前版本不支援後臺執行。
