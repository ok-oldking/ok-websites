能做什么

自动化任务

钓鱼、采集、领取月卡、技能连点、组队确认、协会狩猎、单人副本等。

多语言识别

根据功能提供简体中文、繁体中文、英文及日文客户端支持。

MIDI 与教学谱面

支持 MIDI 演奏、可视化，以及游戏内教学谱面的自动演奏。

运行要求

  • Windows 操作系统与前台运行的游戏窗口
  • 16:9 游戏分辨率，最低 1280×720
  • 使用源码运行时仅支持 Python 3.12
  • 部分任务需要 Npcap 或 WinDivert 提供网络包捕获能力
