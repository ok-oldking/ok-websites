疑难解答

提交问题前，请依次检查以下项目：

  1. 客户端语言：非中文客户端需要在应用设置中指定正确的游戏语言。
  2. 采集识别：采集依赖 OCR。调整视角，避免任务引导遮挡采集按钮。
  3. 解压目录：将程序解压到只包含英文字符的目录。
  4. 杀毒软件：将下载目录与安装目录加入杀毒软件和 Windows Defender 的白名单。
  5. 显示设置：使用 16:9 分辨率和默认亮度，关闭显卡滤镜、锐化及 FPS 叠加层。
  6. 按键绑定：在应用中同步游戏内的自定义按键；设置页未列出的按键不受支持。
  7. 软件版本：确认正在使用最新版本的 ok-star-resonance。
  8. 副本移动错误：切换抓包目标网卡，或使用 WinDivert 抓包。
  9. 仍未解决：提交 Issue，并附上错误发生时的屏幕截图和脚本日志。

提交问题时请提供

  • ok-star-resonance 版本与游戏客户端语言
  • Windows 版本、游戏分辨率和显示缩放比例
  • 触发问题的任务及复现步骤
  • 错误发生时的截图与相关日志
  • 使用 Npcap 还是 WinDivert（如果任务依赖抓包）

请勿上传真实用户抓包、账号资料或其他敏感信息。
