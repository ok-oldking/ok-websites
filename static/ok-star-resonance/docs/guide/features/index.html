特性

  • 支持任意 16:9 分辨率，窗口化和全屏均可，最低 1280×720。
  • 支持基于 PushDeer 的状态通知，配置方法见 PushDeer 官方说明。
  • 支持用户自定义脚本。
  • 通过屏幕捕获、OCR、模板匹配、目标检测与网络包捕获感知游戏状态。
  • 通过 Windows 接口模拟键盘和鼠标操作，不读取游戏内存，不修改游戏文件，不注入游戏进程。

!!! note

游戏窗口必须保持在前台；当前版本不支持后台运行。
