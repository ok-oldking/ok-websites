日常任務

返回：文件索引 / README

概述

日常卡片不再使用「配置選擇」下拉框隱藏引數；任務選擇直接按固定執行塊展開。每個列表項表示是否參加本輪一鍵日常，列表內部順序由程式固定，不允許使用者把共享狀態或戰鬥任務拆散重排。

子任務引數仍在各自任務卡片上配置，並支援在「賬號配置」頁按賬號覆蓋。日常中的刷體力和自動送貨分別使用「日常刷體力」「日常自動送貨」卡片，其配置與單獨執行的「刷體力」「自動送貨」分開儲存。

如果出現反覆按 ESC 的情形，請調高『設定/主介面單次動作後延遲』（建議 1.5 以上）。

子任務和執行順序

固定順序定義在 DailyTask.py 的 build_task_plan()：

flowchart TD
    A[启动日常任务] --> B[帝江号块\n送礼 → 整理 → 收菜]
    B --> C[其他日常\n收邮件 → 转交委托 → 地区建设 → 造装备 → 收信用 → 买信用商店]
    C --> D[战斗块\n刷体力 → 演算]
    D --> E[奖励块\n活动奖励 → 日常奖励]
    E --> F{自动送货已启用?}
    F -->|否| H[最终归位]
    F -->|是| G[自动送货]
    G -->|成功| H
    G -->|失败/异常| X[停止后续任务并关闭游戏]
    H --> I[任务结束]

預設任務選擇：

  • 帝江號任務：送禮、帝江號整理、帝江號收菜。
  • 其他任務：收郵件、轉交運送委託、地區建設、造裝備、收信用、買信用商店。
  • 戰鬥任務：刷體力、演算。
  • 獎勵任務：活動獎勵、日常獎勵。
  • 自動送貨任務：預設關閉。
  • 收尾任務：預設執行「傳送到帝江號右側傳送點」。

「帝江號整理」「帝江號收菜」連續執行時會複用已確認的帝江號狀態。戰鬥任務固定連續執行。獎勵固定放在普通業務任務之後。

自動送貨是獨立的高風險長流程，固定在獎勵之後、最終歸位之前。自動送貨只有在完整確認送達後才算成功；任一關鍵步驟返回失敗或拋異常時，一鍵日常會立即停止，跳過最終歸位與後續外部命令，並關閉遊戲，避免攜貨狀態下再次協議傳送。

外部命令預設在任務最後執行；若自動送貨失敗導致關鍵任務中止，則位於任務末尾的外部命令也會被跳過。可將「外部命令執行時機」改為「任務最開始」使其最先執行。

多賬號模式（必須先在遊戲中登入過列表內賬號，並保持任意賬號已登入）

  1. 首先嚐試切換第一個賬號
  2. 切換賬號後執行日常
  3. 完成日常後嘗試切換第二個賬號
  4. 迴圈直到沒有賬號可以切換

子任務介紹

送禮

檢查單：「帝江號/劍橋」可傳送，「幹員聯絡臺」可用，在『⭐地區建設』中啟用「買物資」，並開啟『是否買禮物』確保禮物充足。

通過「帝江號/幹員聯絡臺/贈送禮物」提升員好感度。如果途中偶遇幹員，則直接互動完成送禮。

角色會傳送到「帝江號/劍橋」，然後走向「幹員聯絡臺」，最後互動完成送禮。

選項：『⭐送禮』『送禮任務最多嘗試次數』『一次送禮個數』『優先送禮物件』。當前預設分別為開啟、2、2 和角色列表首項。

帝江號整理

檢查單：「帝江號」區域可達，背包介面可正常開啟；「簡易製作介面有可製作的物品」可用。確認開啟「一鍵存放」前不會將治療藥等可用道具誤存入倉庫。

「帝江號整理」合併了「帝江號一鍵存放」與「簡易製作」，傳送至帝江號並開啟背包後按配置依次執行，共享傳送與開背包步驟。該任務沒有獨立開關，任一子選項啟用即執行。

  • 『⭐帝江號一鍵存放』（預設關閉）：是否在「帝江號」開啟背包並點選「一鍵存放」。任務會傳送至帝江號，按 B 開啟背包，通過 OCR 識別「存放」按鈕後點擊。

    注意：僅直接點選「一鍵存放」，請確認一鍵存放選項中不含可用道具項再開啟此選項。

  • 『⭐簡易製作』（預設開啟）：是否前往「簡易製作介面」製作物品。

選項：『⭐帝江號一鍵存放』『⭐簡易製作』

收郵件

檢查單：「郵箱」可用。

是否前往「郵箱」領取郵件。

選項：『⭐收郵件』

據點兌換

檢查單：「地區建設/據點管理」可用，至少一個據點可交易。在『⭐地區建設』中啟用「買物資」確保排程券不溢位。

在「地區建設/據點管理」中通過交易獲得排程券。

程式會遍歷所有地區所有據點，儘可能獲得全部排程券。程式支援的交易貨品 詳見檔案 world_map.json 中的列表 goods_dict 。

新增支援的貨品：四號谷地的 紫晶質瓶、紫晶零件，以及武陵的 息壤、赤銅零件、分離芯。

選項：『⭐據點兌換』『交易貨品優先序列』『據點兌換僅購買優先商品』

開啟『據點兌換僅購買優先商品』後，僅當「交易貨品優先序列」不為空時，只兌換其中的商品；優先序列為空時按原邏輯兌換。

交易貨品優先序列

選項『交易貨品優先序列』預設為空，此時程式會識別 據點接受的貨品，對於其中 程式支援的交易貨品 按照 隨機順序 交易。

如果想要程式按順序進行交易，可以在選項『交易貨品優先序列』中 依次填入貨品名稱或正規表示式，並用英文逗號 , 隔開 ，如此以來：

  • 對於 優先貨品 ，如果同時屬於 據點接受的貨品 和 程式支援的交易貨品 ，那麼按照 填寫順序 交易。
  • 對於其它貨品，在優先貨品後按照隨機順序交易。
  • 錯誤的/據點不接受的/程式不支援的 貨品名稱會被忽略。

填寫當前據點支援的完整貨品名稱時，按名稱精確匹配；其它條目按正規表示式搜尋貨品名稱。息壤 與 重息壤 是不同貨品：填寫 息壤 只匹配息壤，不會匹配重息壤或其它名稱含“息壤”的貨品；若要匹配所有名稱含“息壤”的貨品，可填寫 .*息壤.*。

例子

遊戲版本1.1，四號谷地 20晶体外壳 + 24柑实罐头 + 18精选荞愈胶囊 + 18高容谷地电池 畢業滿礦產線，武陵 6优质芽针针剂 + 12中容武陵电池 版本畢業產線。

選項『交易貨品優先序列』可以填入 晶体外壳,\b柑实罐头,精选荞愈,高容谷地,优质芽针,中容武陵，這樣可以在四號谷地節餘電池（搬運發電減少武陵電池消耗）並且在武陵優先消耗藥品（防止藥品爆倉阻塞汙水堵住電池產線）。

轉交運送委託

檢查單：「地區建設/倉儲結點/委託運送列表」和「我轉交的委託」可用。

是否在「地區建設/倉儲結點」中領取一次「我轉交的委託」獎勵，並轉交全部運送委託。程式會在首次進入任意地區的「倉儲結點」時先領取獎勵，然後遍歷所有區域轉交全部委託。

可能出現 委託未領取/貨物摔壞 情形，不能確保獲得最大收益。

選項：『⭐轉交運送委託』。獎勵領取預設啟用。

日常自動送貨

在「日常任務 / 自動送貨」列表中選擇「自動送貨」後，按「日常自動送貨」卡片的「目標券數」「地區切換」和「到達方式」接取並完成運輸委託。賬號迴圈由「日常任務」負責，測試路徑和獨立執行模式只在「自動送貨」任務中使用。

一鍵日常把自動送貨固定安排在獎勵之後、最終歸位之前。只有完整確認提交成功才繼續最終歸位；若任一關鍵步驟失敗或拋異常，會立即終止後續日常並關閉遊戲。

造裝備

檢查單：「裝備製造/套組裝備製造」可用。裝備原件日產不小於50。

是否前往「裝備製造/套組裝備製造」並製作一件 列表首位 的裝備。請確保有足夠的 裝備原件 和排程券。

選項：『⭐造裝備』

收信用

檢查單：「帝江號」區域可達。擁有至少25個好友。「採購中心/信用交易所」可用。

是否前往好友的「帝江號」並在「訪客終端」上進行助力獲得信用。助力結束後，前往「採購中心/信用交易所」收取全部助力。

若選項『嘗試僅收培育室』開啟，則優先嚐試僅助力好友「帝江號」上的「培養倉」。如果不能，至少助力一次其它艙室。

選項：『⭐收信用』；引數『嘗試僅收培育室』在獨立任務「收信用」的卡片上配置（該任務也可單獨執行，引數支援在「賬號配置」頁按賬號覆蓋）。

帝江號收菜

檢查單：「帝江號」區域可達。

是否執行以下任務的總開關：收集線索、使用製造艙助力

選項：『⭐帝江號收菜』

收集線索

檢查單：「帝江號/會客室」區域可達。

是否前往「帝江號/會客室」收集全部線索。若集齊線索，則開啟情報交流。

如果想要提高情報交流頻率（獲得更多的信用來兌換抽卡資源），建議多加好友。

選項：『⭐帝江號收菜』中的「收集線索」

使用製造艙助力

好友可為你的製造艙提供助力，你可在製造時使用這些助力。

選項：『⭐帝江號收菜』中的「使用製造艙助力」

買信用商店

檢查單：「採購中心/信用交易所」可用。

是否在「採購中心/信用交易所」採購。每輪優先購買「武庫配額」「嵌晶玉」及識別到的折扣商品，並最多按 80/120/160/201 信用成本重新整理；只有預計重新整理後信用嚴格大於固定值 210 才會重新整理。不能繼續重新整理時，還會嘗試購買頁面中其他可購商品。

『信用商店保留信用』是購買成功後的停止閾值：程式不會在購買前預留這部分信用，而是在扣除商品價格後，剩餘信用小於等於該值時停止後續採購。該配置不控制重新整理；重新整理始終使用上述固定 210 判定。

選項：『⭐買信用商店』『信用商店保留信用』

買賣貨

檢查單：「帝江號」區域可達。擁有至少25個好友。「地區建設/物資排程/彈性需求物資」可用。在『⭐地區建設』中啟用「據點兌換」確保排程券充足、「買物資」確保排程券不溢位。

是否在「彈性需求物資」與好友交易賺取排程券。自動獲取貨物資訊，然後用價格上下限判定是否交易。（除非可購買數量即將溢位，這種情況下必定交易。）

『武陵』『四號谷地』等地區開關只控制該地區的買賣貨；關閉後，仍會執行已啟用的據點兌換和買物資。

『地區範圍模式』『地區列表』控制整個地區的執行範圍，預設「排除所選地區」且列表為空，表示執行全部地區。勾選『使用獨立地區配置』後採用當前任務的範圍，否則採用全域性地區配置。

升級時保留舊地區交易開關，不把它轉換成整地區排除。曾被舊遷移自動生成的排除項，僅在遷移前備份存在、當前範圍與自動生成結果一致時恢復；恢復同時保留原來的交易開關，任務配置和賬號獨立配置均適用。已修改的範圍或缺少備份的配置保持現狀，可手動檢查地區列表。

只買不賣模式下，只進行購買操作，不進行賣出操作。並不會獲取所有資訊以加速任務流程。

當前 程式支援的交易物資 詳見檔案 world_map.py 中的列表 exchange_goods_dict 。

選項：『⭐地區建設』的「買賣貨」『只買不賣』『武陵買入價』『武陵賣出價』『武陵』『四號谷地買入價』『四號谷地賣出價』『四號谷地』

買物資

檢查單：「地區建設/物資排程/穩定物資需求」可用。在『⭐地區建設』中啟用「據點兌換」確保排程券充足。

是否在「地區建設/物資排程/穩定物資需求」中通過排程券購買物資。依次購買「日用消耗」「工業貨品」「人文物產」首行某個物品。

選項『購物白名單』預設留空，表示購買「日用消耗」「工業貨品」首行首個物資；若『是否買禮物』為 true，也會購買「人文物產」首行首個物資。

該選項可以填入用 英文逗號(,) 隔開的若干 正規表示式 ，如果任一可以匹配首行的某個物資，那麼購買，如果都不匹配，那麼跳過。推薦設為 刻写,助剂,理智,寻访,高级,高阶,折金票 。

建議手動購完 不重新整理的一次性物資，以避免奇怪的問題（雖然能相容）。

選項：『⭐地區建設』的「買物資」『購物白名單』『是否買禮物』

刷體力

在「日常任務」卡片開啟『⭐刷體力』後，按「日常刷體力」卡片的關卡、刷本序列等引數執行。「日常刷體力」也可單獨執行；單獨的「刷體力」卡片儲存另一份配置。詳見 體力本.md 。

活動獎勵

檢查單：「活動中心/每週事物」可用。

是否按『⭐活動獎勵』多選項領取「活動中心」中的獎勵。當前三個選項預設全部選中。

選項：『⭐活動獎勵』，可選「周常獎勵」「理智補給」「刮刮樂」

日常獎勵

檢查單：「行動手冊/日常」和「通行證」可用。

是否領取「行動手冊/日常」和「通行證」中的獎勵。

選項：『⭐日常獎勵』

傳送到帝江號右側傳送點

檢查單：帝江號區域可達。

傳送到「帝江號」右側傳送點。

選項：『⭐傳送到帝江號右側傳送點』

執行外部命令

檢查單：外部程式可通過命令列直接啟動。

在日常任務最開始或最後執行一次外部命令，通過「外部命令執行時機」下拉框選擇。可通過選項控制是否等待命令退出，也可在檢測到目標命令已執行時跳過本次啟動。可結合其他能夠通過命令列執行特定任務的指令碼使用，以更好地實現遊戲日常處理。

選項：『⭐執行外部命令』『外部命令』『外部命令起始於』『外部命令等待退出』『外部命令已執行時跳過』『外部命令執行時機』

命令示例（參考命令列啟動任務的寫法，儘量保持簡短）：

# MXU（Windows）：开机自启动模式，指定实例（任务标签页）名
