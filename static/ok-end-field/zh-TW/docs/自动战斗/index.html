自動戰鬥

返回：文件索引 / README

概述

自動檢測戰鬥狀態，在進入戰鬥後自動執行技能釋放邏輯，戰鬥結束後停止本輪並繼續等待下一場。它是註冊的觸發式任務，需在任務介面啟用；只在檢測到至少 1 格技力且隊伍 UI 存在時接管戰鬥。

戰鬥邏輯與「刷體力」中的戰鬥邏輯相同，詳見 體力本.md。

觸發流程

flowchart TD
    A[启用自动战斗触发任务] --> B[轮询截图]
    B --> C{检测到战斗状态}
    C -->|否| B
    C -->|是| D[AutoCombatLogic 接管]
    D --> E[读取全局战斗配置]
    E --> F[执行普通/排轴/实时条件战斗]
    F --> G{战斗结束}
    G -->|否| F
    G -->|是| H[释放检测器和状态]
    H --> B

使用要求

確保解析度大於等於1920x1080（1080P），低於 1080P 不保證正常執行

戰鬥配置（全域性共享）

所有戰鬥相關的配置項現在集中在 「全域性配置 → 戰鬥配置」 中統一管理， 一次配置即可應用到「自動戰鬥」「刷體力」「日常任務」等所有涉及戰鬥的任務，無需多處重複設定。

技能釋放

「戰技」釋放角色順序是可排序列表，預設 1,2,3，可從 1 至 4 中選擇且不允許重複。普通模式在連攜技和終結技均未釋放時按該列表迴圈出技。

啟動技能點數

當「技力條」達到該數值時，開始執行技能序列。取值範圍 1–3。

完成通知

戰鬥結束後是否傳送系統通知。

無數字操作間隔

戰鬥中週期觸發鎖敵 + 向前閃避的最小間隔秒數，預設 6；執行時限制為 1 至 30 秒。

進入戰鬥後的初始等待時間

進入戰鬥後等待該時間（秒）後才開始釋放技能。

啟用排軸

啟用後按照「排軸序列」中定義的順序使用技能。某個動作連續 5 秒未成功時，本場戰鬥永久回退普通邏輯。

詳見 排軸.md。

排軸序列

技能釋放的自定義順序字串，僅在「啟用排軸」開啟時生效。

格式和用法詳見 排軸.md。

啟用即時條件

啟用後忽略排軸。可在面板編輯觸發條件和序列。

當即時條件序列為空或全部非法時，自動回退普通模式。

立即釋放終結技 / 立即釋放連攜技

本幀無條件動作產出時，按開關嘗試立即釋放終結技或連攜技。優先順序：終結技 > 連攜技。

僅在即時條件啟用時生效。
