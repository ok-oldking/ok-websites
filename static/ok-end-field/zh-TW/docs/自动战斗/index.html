自動戰鬥

返回：文件索引 / README

概述

在“業務與戰鬥 → 大世界”頁啟用自動戰鬥。 自動戰鬥檢測到至少 1 格技力且隊伍介面存在時接管。 戰鬥結束後，自動戰鬥繼續等待下一場。

戰鬥邏輯與“刷體力”相同，詳見體力本。 “日常一條龍 → 戰鬥”的抽屜保留體力、關卡和入場設定。

觸發流程

flowchart TD
    A[启用自动战斗触发任务] --> B[轮询截图]
    B --> C{检测到战斗状态}
    C -->|否| B
    C -->|是| D[战斗入口接管]
    D --> E[读取当前生效的战斗配置]
    E --> F[执行技能时间排轴或所选战斗模式]
    F --> G{战斗结束}
    G -->|否| F
    G -->|是| H[释放检测器和状态]
    H --> B

使用要求

確保遊戲畫面寬高比為 16:9，且解析度至少為 1600x900（900P），低於 900P 不保證正常執行

戰鬥配置

戰鬥引數集中在“業務與戰鬥 → 自動戰鬥”。 “儲存敵人檢測除錯幀”位於同頁的“敵人檢測”分組。 “配置範圍”列出通用設定、任務和已有的賬號專用設定。 頁面註明當前範圍使用的配置來源。 點選卡片的“配置”，在右側面板編輯引數。 按 Esc、點選遮罩或關閉按鈕可關閉面板。 切換頁面或配置範圍時，面板關閉。

  • 通用設定：修改後自動儲存，影響沿用通用設定的任務。
  • 專用設定：修改後點選面板中的“儲存並關閉”。切換範圍或離開頁面時也會儲存。
  • 改用專用設定：恢復當前範圍已儲存的專用引數。
  • 改用通用設定：停止使用專用引數，保留已儲存的值。

賬號的戰鬥配置開關覆蓋任務開關。 啟用專用設定時，賬號引數覆蓋任務引數。 其餘範圍讀取通用設定。 任務執行時，頁面禁止修改引數和切換配置範圍。

主題入口為“系統與環境 → 設定 → 應用主題”。 淺色使用紙白與墨黑；深色使用中性灰與淺墨，兩套主題的元素一一對應。 勾選框、編號牌和主按鈕使用墨色。 黃色只用於當前導航項、當前頁籤、已開啟的開關和按鈕懸停。 卡片懸停使用中性邊框，頁籤焦點顯示虛線框。 停用按鈕和選項使用灰色，已選狀態保留勾選標記。 配置來源提示左側有黃色豎條。 任務狀態同時顯示邊框和文字，切換主題後立即換色。 等待執行顯示虛線框，執行中顯示實線框，已暫停顯示黃底。 英文眉標和編號使用內建 Saira 字型。 中文使用系統介面字型。 開關可通過 Tab 鍵聚焦，按空格鍵切換。 “恢復預設大小”按鈕位於標題欄，在最小化按鈕左側。 點選後，視窗恢復為 1440×900 並居中。 螢幕空間不足時，視窗按可用區域縮小。 縮窄視窗後，頁籤和操作區換行。 單行任務說明和網址顯示省略號，懸停可檢視全文。 配置表單按已有依賴關係縮排子項。 一級項之間有分隔線；同組子項之間不加線。 各頁配置使用同一個側邊面板。 面板保留原有欄位、重置操作和儲存規則。 沒有可編輯內容的專案隱藏“配置”入口。 配置標題省略星號，儲存時沿用原有配置鍵。 日常頁籤依次為“帝江號、戰鬥、獎勵、其他”。 賬號頁從“賬號基礎設定”開始編號。 賬號列表和任務選擇通過各自的“配置”編輯。 “任務屬性配置”直接開啟當前賬號的任務引數。 賬號基礎面板的“儲存並關閉”會儲存賬號列表。 入口卡片的說明顯示在標題右側；窄窗下省略長文本。

終結技釋放方式

可以選擇終結技釋放方式：

  • 長按技能按鍵（預設）
  • Alt + 技能按鍵

技能時間排軸與戰鬥模式

「技能時間排軸」預設關閉。開啟後使用獨立的時間排軸排程，詳見 技能時間排軸說明。關閉時顯示「戰鬥模式」下拉框，同一時刻只選擇一種策略：

普通模式 按指定角色順序迴圈釋放戰技 技能釋放、啟動技能點數、自動釋放推薦技能

即時條件 按即時條件選擇動作；序列為空或全部非法時回退普通模式 即時條件序列、立即釋放終結技、立即釋放連攜技

「啟用排軸」「啟用即時條件」「自動技能列表」「傷害優先排序」舊布林開關只保留用於配置相容，不再作為獨立開關顯示。普通模式的相關設定如下。

技能釋放

「戰技」釋放角色順序是可排序列表，預設 1,2,3，可從 1 至 4 中選擇且不允許重複。普通模式在連攜技和終結技均未釋放時按該列表迴圈出技。

啟動技能點數

當「技力條」達到該數值時，開始執行技能序列。取值範圍 1–3。

完成通知

戰鬥結束後是否傳送系統通知。

無數字操作間隔

戰鬥中週期觸發鎖敵 + 向前閃避的最小間隔秒數，預設 6；執行時限制為 1 至 30 秒。

進入戰鬥後的初始等待時間

進入戰鬥後等待該時間（秒）後才開始釋放技能。該配置屬於戰鬥入口控制，不屬於技能策略；即使啟用「技能時間排軸」，也仍然生效。

僅協議空間啟用初始等待

預設關閉。關閉時保持原行為：所有戰鬥都使用「進入戰鬥後的初始等待時間」。

開啟後，僅協議空間保留這段等待；普通戰鬥檢測到戰鬥 UI 後直接開始自動操作。協議空間優先複用戰鬥邏輯現有的終結技就緒檢測：當前可見隊員的終結技全部就緒時視為熱啟動；左上角「撤離」按鈕仍作為兜底特徵。

這個選項用於協議空間“戰鬥 UI 已出現，但敵人尚未正式進場”的開局階段，避免因為戰鬥狀態提前成立而過早釋放技能。

固定排軸

將「戰鬥模式」選為「固定排軸」後，按照「排軸序列」中定義的順序使用技能。某個動作連續 5 秒未成功時，本場戰鬥永久回退普通邏輯。

詳見 排軸.md。

排軸序列

技能釋放的自定義順序字串，僅在「戰鬥模式」選擇「固定排軸」時顯示並生效。

格式和用法詳見 排軸.md。

即時條件

將「戰鬥模式」選為「即時條件」後，可在面板編輯觸發條件和序列。

當即時條件序列為空或全部非法時，自動回退普通模式。

立即釋放終結技 / 立即釋放連攜技

本幀無條件動作產出時，按開關嘗試立即釋放終結技或連攜技。優先順序：終結技 > 連攜技。

僅在「戰鬥模式」選擇「即時條件」時顯示並生效。
