安裝

系統要求

  • 作業系統：Windows 10 或 Windows 11。
  • 遊戲解析度：要求 16:9，1920×1080（1080P）及以上；低於 1080P 不保證正常執行。
  • 執行路徑：建議使用不含中文和特殊許可權限制的目錄。
  • 遊戲語言：當前部分識別功能僅支援簡體中文。

使用安裝包

這是大多數使用者推薦的方式。請在 GitHub Releases 下載最新的 setup.exe 安裝包，而不是 Source Code 原始碼壓縮包。

網路訪問 GitHub 不穩定時，可使用 Mirror醬、百度網盤 或 夸克網盤。

安裝完成後，從桌面快捷方式或開始選單啟動 ok-ef。

從原始碼執行

原始碼執行適合二次開發和除錯。完整過程見從原始碼執行。

git clone --recurse-submodules https://github.com/AliceJump/ok-end-field.git
Set-Location ok-end-field
uv sync
uv run python main.py

!!! warning "許可權與安全軟體" 建議以管理員許可權執行程式，使其與遊戲視窗許可權一致。若程式無法啟動或檔案被刪除，請將安裝目錄加入安全軟體信任列表。
