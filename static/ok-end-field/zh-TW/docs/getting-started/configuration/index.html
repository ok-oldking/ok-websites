使用前配置

執行自動化前，請完成以下檢查。這些設定會直接影響識別和輸入的穩定性。

遊戲畫面

  • 使用 16:9 解析度，要求 1920×1080（1080P）及以上；低於 1080P 不保證正常執行。
  • 使用遊戲預設亮度；關閉 NVIDIA Freestyle、AMD 影像濾鏡、銳化和畫面覆蓋層。
  • 執行時不要最小化遊戲視窗，也不要鎖屏或讓螢幕熄滅。
  • 戰鬥和導航任務建議保持穩定 60 FPS。

輸入與視窗

  • 若修改過遊戲按鍵，請在應用設定中同步支援的按鍵配置。
  • 遊戲視窗和自動化程式的許可權應一致；建議均以管理員許可權啟動。
  • 前臺執行任務期間避免移動滑鼠或手動點選遊戲視窗。
  • 多賬戶任務需先在遊戲中登入過待執行賬號。

首次執行

  1. 啟動遊戲並進入與目標任務相符的場景。
  2. 啟動 ok-ef，在任務列表中選擇要執行的任務。
  3. 閱讀該任務的前置條件和配置說明，再點選開始。
