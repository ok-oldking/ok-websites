功能概覽

功能會隨版本變化；請以應用中可見的任務和最新發布說明為準。

日常與資源

  • 日常任務：送禮、帝江號、地區建設、獎勵領取、刷體力及演算等流程。
  • 刷體力：普通、高階、危境和能量淤積點，支援戰鬥配置與排軸。
  • 運送委託接取：按券種和金額篩選並接取委託。
  • 自動送貨：執行配置的委託接取與送貨路徑。
  • 倉庫物品轉移：跨倉庫批次轉移指定物品。

後臺觸發（不完全支援）

後臺執行不完全支援：僅部分任務支援，涉及鍵盤操作的部分暫不支援。

  • 自動戰鬥：檢測戰鬥狀態後按普通、排軸或即時條件邏輯釋放技能。
  • 自動互動：自動跳過劇情並執行地圖傳送互動。
  • 自動拾取：按白名單拾取，並根據黑名單過濾。
  • 物品導航與即時檢測：通過官方地圖或本地 WebSocket 位置資料導航，並提供 YOLO 除錯能力。

配置與排程

  • 賬號配置：多賬號和賬號獨立的任務配置。
  • Windows 計劃任務：定時啟動已註冊的一次性任務。
  • 滑鼠轉向標定：校準遊戲內滑鼠視角旋轉系數。
