裝備詞條識別輪子

返回：文件索引 / README

歷史“畢業基質識別”一次性任務已移除，不再提供自動遍歷、上鎖、解鎖或棄置等 UI 自動化行為。

本目錄僅保留可複用的識別輪子，供後續任務或離線工具按需組合。

保留內容

OCR 面板解析

位置：src/essence/essence_recognizer.py

能力：

  • parse_essence_panel(texts)：從 OCR Box 列表解析面板名稱、來源、詞條和等級。
  • read_essence_info(task)：通過任務上下文截圖 + OCR 後呼叫 parser，作為後續任務的便捷入口。
  • attach_essence_levels(info, level_boxes)：將單獨 OCR 到的等級 Box 按垂直順序附加到已解析詞條。

CSV 規則匹配

位置：src/essence/weapon_data.py

能力：

  • load_weapon_data(path)：讀取 weapon_data*.csv。
  • discover_weapon_data_language_options(dir)：發現多語言 CSV 選項。
  • match_weapon_requirements(requirements, entry_names)：按詞條集合匹配規則。

模板資產

位置：assets 與 ok_templates

保留 essence_* 模板和 COCO 類別，用於後續重新組合 UI 檢測流程；當前專案不再註冊對應任務。

已移除內容

  • src/tasks/EssenceScanTask.py
  • configs/EssenceScanTask.json
  • docs/毕业基质识别.md
  • 依賴任務上下文的 tests/TestEssenceGoldGrid.py

後續複用建議

如果要重新實現相關能力，建議分層組合：

  1. 任務層只負責進入頁面、選擇格子、滾動等 UI 流程。
  2. OCR 層呼叫 read_essence_info(task) 或 parse_essence_panel(texts)。
  3. 規則層呼叫 load_weapon_data() 與 match_weapon_requirements()。
  4. 危險操作（上鎖、解鎖、棄置）必須單獨加確認配置和日誌，不應寫入解析輪子。

這樣可以讓解析能力複用於測試、離線分析、除錯任務或未來的新 UI 流程。
