修改模板快速開始

面向 AliceJump/ok-end-field 無許可權貢獻者，專用於修改遊戲截圖模板。

倉庫 角色
AliceJump/ok-end-field 上游主倉庫
AliceJump/ok-end-field-x-anylabeling-asset 模板原始檔 (ok_templates/，submodule，預設分支 main)
你的账号/... 你的兩份 fork

先搞懂架構

ok_templates/  (子仓库: 原始 PNG + 对应 AnyLabeling JSON + coco_annotations.json)
     │ TemplateTab → Save → "assets (standalone app)"
     ▼
assets/images/ + assets/coco_annotations.json  (主仓库生成物)
src/data/FeatureList.py                         (主仓库生成的标签枚举)
     │
     ▼
self.find_feature(feature=fL.xxx)
     → RuntimeMixin.find_feature
     → get_feature_by_resolution (基础名 / _2k / _4k)
     → ok-script BaseTask.find_feature / FeatureSet
     → OpenCV 模板匹配

關鍵：ok_templates/ 中與截圖同名的原始 PNG、標註 JSON 以及彙總的 coco_annotations.json 才是模板原始碼；主倉庫的 assets/images/、assets/coco_annotations.json 和 src/data/FeatureList.py 是 Save 生成物。模板改動必須同時提交子倉庫原始碼和主倉庫生成物。

① Fork 兩個倉庫

倉庫 操作
AliceJump/ok-end-field GitHub → Fork
AliceJump/ok-end-field-x-anylabeling-asset GitHub → Fork

② Clone（含 submodule）

git clone --recursive https://github.com/你的账号/ok-end-field.git
cd ok-end-field
git remote add upstream https://github.com/AliceJump/ok-end-field.git
git fetch upstream
git switch -c update-templates upstream/master

如果已 clone 但沒初始化：git submodule update --init ok_templates

主倉庫的 origin 應指向你的 fork，upstream 應指向 AliceJump/ok-end-field。主倉庫當前預設分支是 master；提交前應確認功能分支基於最新的 upstream/master。

③ 配置子倉庫 remote → 從 main 簽出分支

cd ok_templates
git remote rename origin upstream
git remote add origin https://github.com/你的账号/ok-end-field-x-anylabeling-asset.git
git fetch --all --prune
git switch --create main --track upstream/main
git switch -c update-x-template
git remote -v
cd ..

初始化 submodule 後通常處於 detached HEAD，且 .gitmodules 配置的 origin 指向上游。上面的命令將該 remote 保留為 upstream，再把你的 fork 設為可推送的 origin。如果本地已經存在 main，使用 git switch main 和 git pull --ff-only upstream main，不要再次執行 --create。

標籤名必須與 src/data/FeatureList.py 中的值及程式碼呼叫一致。當前約定是小寫英文 snake_case，按語義使用字首/字尾，例如角色聯絡頭像用 contact_<name>，戰鬥頭像用 battle_icon_<name>，圖示用 <name>_icon，同類變體用 _2、_3。解析度專用模板只追加 _2k 或 _4k；程式碼通常傳不帶解析度字尾的基礎名，例如 self.find_feature(feature=fL.esc)，由 get_feature_by_resolution() 按視窗寬度選擇 esc、esc_2k 或 esc_4k。不要沿用倉庫中不存在的 char_、box_ 等舊字首約定。

常見錯誤

錯誤 原因 解決
Permission denied push 失敗 remote 仍指向上游 git remote set-url origin 改到你的 fork
git submodule status 出現 + 子倉庫當前 checkout 的 commit 與主倉庫索引記錄的 gitlink 不同；不表示該 commit 一定“不在上游” 用 git diff --submodule=log -- ok_templates 確認差異；應更新時在主倉庫暫存 ok_templates，不應更新時切回索引記錄的 commit
git submodule status 出現 - / U - 表示未初始化；U 表示 gitlink 有合併衝突 初始化 submodule；衝突則先在子倉庫選定正確 commit，再在主倉庫暫存 gitlink
submodule dirty 未提交修改 cd ok_templates && git status
找不到模板 not found in featureDict 沒 compress / 名稱不對應 確認 category name 與程式碼呼叫一致
cv2.error 模板比搜尋區域大 檢查 bbox 範圍
