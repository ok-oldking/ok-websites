五、關鍵設計決策

  1. 登入互動為什麼要自己寫 click_text() 而不是用框架的 find_feature + click？
    因為登入介面的 UI 元素是文字（"最近"、"登入"按鈕文字），不是預註冊的特徵圖片模板，所以只能用 OCR 識別文字位置再點選。

  2. 為什麼 click_text 不用框架的 self.click() 而用 pyautogui.click()？
    self.click() 走的是 EfInteraction → PostMessage 向視窗傳送訊息，但遊戲登入介面（使用者中心 WebView）可能不響應 PostMessage 滑鼠事件，需要用全域性級別滑鼠事件（pyautogui.click + SetCursorPos）。

  3. 為什麼 login_screenshot 不用框架的 self.executor.frame？
    遊戲彈窗/登入介面可能無法被框架的 DesktopDuplication / BitBlt 捕獲（如 UWP 彈窗或某些渲染層覆蓋），pyautogui.screenshot() 是後備方案。
