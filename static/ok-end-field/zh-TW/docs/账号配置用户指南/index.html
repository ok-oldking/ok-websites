賬號配置使用者指南

返回：文件索引 / README

這是一份面向日常使用的簡版文件，只講怎麼配、怎麼用。

1. 先理解兩套配置

  1. 賬號配置頁：管理賬號身份（賬號名/手機號）、地圖同步 content 和賬號任務覆蓋引數，不填密碼。儲存時會刪除舊格式中的密碼文本。
  2. 任務配置頁：管理任務本身開關與執行賬號列表。當前 AccountMixin 會相容 账号,密码 舊格式，但只讀取賬號名，密碼欄位會被忽略且不會用於登入。

2. 快速上手

  1. 開啟賬號配置頁，在“賬號列表”每行填一個賬號名（手機號）。
  2. 點選“儲存賬號列表”。
  3. 選擇賬號和任務，按需修改該賬號在該任務下的覆蓋引數並儲存。
  4. 如需物品導航官方地圖同步，在“地圖同步 content”的單行輸入框中填寫該賬號的 data.content 並儲存。
  5. 回到對應任務頁，填寫執行賬號列表（每行一個賬號名；舊格式 账号,密码 可被相容），並按需開啟：
    • 多賬戶模式
    • 多賬戶獨立配置

3. 關鍵規則

  1. 賬號名（手機號）是使用者側身份鍵；儲存賬號列表時，程式會為新賬號名生成內部 account_id。
  2. 密碼不儲存、不參與身份判定，也不參與登入。
  3. 原賬號名再次儲存會複用內部 account_id；改成新賬號名會被視為新賬號並生成新 ID。舊賬號已有覆蓋或地圖 content 時，舊記錄仍會保留。

4. 常見場景

  1. 只想給某個賬號單獨調引數：
    • 在賬號配置頁選中該賬號和任務，修改後儲存。
  2. 想多賬號輪換跑任務：
    • 確保各賬號曾出現在遊戲登入頁的「最近」列表，在任務頁每行填寫一個完整手機號並開啟多賬戶模式。
  3. 想多賬號獨立配置：
    • 在任務頁開啟多賬戶獨立配置。
  4. 想給物品導航使用某個賬號的官方地圖同步：
    • 在賬號配置頁儲存該賬號的地圖同步 content，再在物品導航任務中選擇“地圖賬號”。
  5. 賬號配置頁看不到某個任務：
    • 該任務當前不支援多賬號獨立配置展示。

7. 常見問題

  1. 為什麼賬號配置頁不填密碼？
    • 因為切換賬號依賴遊戲登入頁的「最近」賬號列表，不輸入密碼。舊格式中的密碼欄位完全忽略。
  2. 我改了賬號配置頁賬號列表，主任務沒跟著變？
    • 正常。賬號頁賬號列表與任務頁賬號列表是獨立的。
  3. 任務頁賬號列表格式寫錯會怎樣？
    • 每行只寫賬號名是正常格式，不需要逗號。空行、賬號名為空的行會被忽略；逗號後的舊密碼欄位也會被忽略。
  4. 為什麼建議填寫完整手機號？
    • 程式按填寫值的後四位點選「最近」賬號。若多個最近賬號後四位相同，可能選錯賬號；請確保後四位唯一。
