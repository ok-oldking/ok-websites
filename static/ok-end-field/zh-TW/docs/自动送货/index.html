自動送貨

返回：文件索引 / README

概述

自動接取當前選擇地區的委託，按照配置路徑將貨物送至對應接收者。正常模式下每個賬號最多執行 3 輪接取與送貨。該任務支援多賬戶執行和多賬戶獨立配置；僅接取、僅送貨或路徑測試模式不進行多賬號輪換。

配置、地區和目標來自 DeliveryTask.py 與 delivery_area.py。

選項和配置

目標券數

可選值來自 DELIVERY_TARGET_TICKET_NUM_OPTIONS，當前為 163000、159000、119000、79800、73100。

介面將其顯示為目標券數優先順序序列，預設 119000，並允許配置多個券數。接單迴圈按照列表順序查詢，命中前面的券數後不會再查詢後續券數；前面的券數沒有可接委託時，才會繼續嘗試下一項。

多賬戶模式

自動送貨既可以作為獨立任務執行，也可以作為日常任務中的 ⭐自动送货 子項執行。獨立任務保留完整的多賬號和測試入口；日常子項複用日常任務的賬號迴圈，只執行完整送貨流程。

  • 開啟「多賬戶模式」後，任務會按「賬號列表」逐個切換賬號執行自動送貨。
  • 開啟「多賬戶獨立配置」後，同一送貨任務可按賬號覆蓋目標券數、地區切換等常規配置；滑索配置位於「全域性配置 / 滑索配置」，跨任務共享，但也可在賬號頁為每個賬號設定獨立滑索覆蓋。
  • 賬號列表每行一個賬號；相容舊格式 账号, 密码，但密碼欄位會被忽略。賬號切換使用遊戲登入頁「最近」列表，不輸入密碼。
  • 獨立任務保留「選擇測試物件」「僅接取」「僅送貨」等除錯選項；日常任務入口不顯示這些選項。

地區切換

通過下拉框選擇當前送貨地區

切換後會使用該地區的：

  • 委託地點識別規則
  • 送貨目標列表
  • 對應的送貨點滑索配置（按地點匹配）

通向{地點}送貨點

從委託地點前往對應送貨點的滑索距離序列

送貨滑索和淤積點滑索在全域性滑索配置中通過分類下拉框分開顯示。賬號頁選擇「滑索配置」後，可以按賬號覆蓋其中任意路線。

決定從已接委託地點前往取貨點的路徑。配置鍵按「通向{地點}送貨點」命名，每個送貨地點一個鍵，武陵當前包含：

  • 「通向武陵城送貨點」（武陵城）
  • 「通向試驗園區送貨點」（試驗園區）

對應地點配置為空時，本輪送貨直接失敗，不會借用另一地點路線。

示例：

50,34

功能選項

是否啟用滾動放大視角

該配置已移動到「全域性配置 / 滑索配置」，送貨和刷體力任務共用同一項設定。

啟用後，在對齊滑索時會自動滾動放大視角。

  • 可能提高對齊成功率
  • 也可能在某些情況下明顯降低成功率

建議：

  • 啟用時儘量使用寬大頭髮或深色頭髮(帽子)(別禮、賽希)
  • 避免使用黃白頭髮或帽子（識別可能受影響）

僅接取

前置：選擇測試物件 =「無」

僅接取當前選擇地區委託，不執行送貨流程。

支援 7.31w、7.98w、11.9w、15.9w 和 16.3w，並按照配置列表從前到後確定接單優先順序。

僅送貨

前置：選擇測試物件 =「無」，且已接取當前選擇地區委託並處於可送貨狀態

啟動自動識別並執行送貨流程。

選擇測試物件

用於除錯或路徑測試。

  • 預設：無（正常執行完整流程）

  • 可選：指定滑索分叉序列（用於單路徑測試）

  • 完整迴圈測試：

    • 會依次測試每個送貨目標的完整流程
    • 需要將任務鎖定在送貨點或其附近

發生異常時終止遊戲

當指令碼檢測到異常情況時，自動關閉遊戲和指令碼，防止後續指令碼其他任務卡死或遊戲資源佔用。

完成後退出

任務完成後自動執行：

  • 退出遊戲
  • 關閉 App

補充說明

所有路徑均為「滑索距離序列」，按順序依次執行。

  • 當前僅配置「武陵」地區，預設地區也是武陵；無效地區值會回退到武陵。

  • 接單時會從委託文本快取地點。武陵城在地圖頂部搜尋傳送點，試驗園區在地圖右側搜尋；未識別地點或缺少該地點配置時，本輪送貨失敗，不會使用通用地圖區域兜底。

  • 滑索推進階段固定使用 E 鍵觸發連線點（底層按鍵輸入），不受通用熱鍵配置影響。

  • 原因是該互動鍵在遊戲內不可改綁，且高頻重複輸入可降低短距離滑索漏觸發機率。
