倉庫物品轉移

返回：文件索引 / README

概述

從「發貨倉庫」取出指定物品，切換到「收貨倉庫」後一鍵存放，迴圈執行指定輪次。適用於跨區倉庫之間的物資搬運（目前僅支援中文版遊戲）。

前置條件

建議在遊戲主介面啟動任務，並確保兩個倉庫均已連線。

任務會自動嘗試開啟背包並執行後續流程。

選項和配置

發貨倉庫

從哪個倉庫取貨。

可選值：

選項 說明
valley4 四號谷地倉庫
wuling 武陵倉庫

預設：valley4

收貨倉庫

將貨物轉運到哪個倉庫。

可選值同發貨倉庫，不能與發貨倉庫相同。

預設：wuling

物品

選擇要轉移的物品名稱。

當前支援的物品列表見原始碼 world_map.py 中的 item_to_warehouse_dict。

轉移輪次

執行倒貨的總輪次數，每輪完成一次「取貨 → 切換倉庫 → 存放」流程。

預設：10

工作流程

flowchart TD
    A[启动仓库物品转移] --> B[打开背包]
    B --> C[检测当前仓库]
    C --> D{当前是否发货仓库}
    D -->|否| E[切换到发货仓库]
    D -->|是| F[进入物品分类页]
    E --> F
    F --> G[通过模板匹配目标物品]
    G --> H[Ctrl + 点击取出]
    H --> I[切换到收货仓库]
    I --> J[点击一键存放]
    J --> K{达到转移轮次}
    K -->|否| C
    K -->|是| L[结束]

注意事項

  • 發貨倉庫與收貨倉庫不能選擇同一個倉庫。
  • 若所選物品圖示無法識別（未在支援列表中），任務將報錯終止。
  • 建議確保兩個倉庫均處於「已連線」狀態後再啟動任務。
