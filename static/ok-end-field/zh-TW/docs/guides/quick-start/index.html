快速上手

啟動任務

  1. 按照使用前配置檢查遊戲視窗、畫面和按鍵設定。
  2. 啟動 ok-ef，進入與任務相符的遊戲場景。
  3. 在應用中選擇任務，並檢查任務的配置項與前置條件。
  4. 點選開始，任務執行期間觀察日誌和遊戲畫面。

日常任務、刷體力、自動戰鬥等功能的配置與限制見功能概覽。

停止與恢復

畫面與預期不一致、遊戲視窗失焦或需要臨時接管時，應立即在應用中停止任務。恢復前重新確認場景、視窗和前置條件，不要依賴長時間重複輸入糾正異常畫面。

定時執行

日常任務、自動送貨、影拓豐碑及遊戲啟動檢查任務支援內建計劃任務。也可以通過 Windows 計劃任務 呼叫已註冊的一次性任務。
