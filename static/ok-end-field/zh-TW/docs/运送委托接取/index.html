運送委託接取

返回：文件索引 / README

概述

自動在「地區建設/倉儲結點/運送委託列表」中搶單，篩選符合條件的高價值委託並自動接取。

前置條件

保持在遊戲主介面即可。任務啟動後會自動執行：

  1. 按 Y 開啟地區建設。
  2. 點選「倉儲節點」。
  3. 點選「運送委託列表」。

隨後進入自動篩選與接取流程，接取成功後自動退出。

選項和配置

接取谷地券

是否搶取「四號谷地」型別的運送委託。

預設：關閉

接取谷地券最低金額(萬)

接取谷地券委託的最低報酬金額（萬），低於此金額的委託不接取。

預設：5.0

接取谷地券最高金額(萬)

接取谷地券委託的最高報酬金額（萬），高於此金額的委託不接取（防止 OCR 誤識別導致接取異常委託）。

預設：40.0

接取武陵券

是否搶取「武陵」型別的運送委託。

預設：開啟

接取武陵券最低金額(萬)

接取武陵券委託的最低報酬金額（萬）。

預設：5.0

接取武陵券最高金額(萬)

接取武陵券委託的最高報酬金額（萬）。

預設：15.0

工作流程

flowchart TD
    A[启动任务] --> B[按 Y 打开地区建设]
    B --> C[点击仓储节点]
    C --> D[打开运送委托列表]
    D --> E{启用武陵券}
    E -->|是| F[切换武陵列表]
    E -->|否| G{启用谷地券}
    G -->|是| H[切换四号谷地列表]
    G -->|否| Z[无券种启用并退出]
    F --> I[OCR 读取金额和按钮]
    H --> I
    I --> J[按金额范围筛选]
    J --> K[按券种图标匹配]
    K --> L{找到目标委托}
    L -->|是| M[点击接取并等待请尽快送达]
    M --> N[接取成功后退出]
    L -->|否| O[滚动列表]
    O --> P{有已记录的刷新按钮}
    P -->|是| Q[满足 5.6 秒间隔后点击刷新]
    P -->|否| R[等待 1 秒后继续重试]
    R --> I
    Q --> I

注意事項

  • 本任務繼承 TriggerTask，但註冊在 onetime_tasks 中，作為使用者手動啟動的一次性搶單流程使用。接取成功後自動退出，不執行送貨操作（送貨請使用 自動送貨）。
  • 同時開啟兩種券時，任務先進入武陵列表，但會在當前列表內按券圖示匹配兩種券；它不會自動切換到四號谷地列表繼續搜尋。只開啟谷地券時才進入四號谷地列表。
  • 列表每輪滾動一次，重新整理後反轉滾動方向；重新整理點選間隔至少 5.6 秒。
  • 當前未定位到重新整理按鈕時會每秒繼續重試，不會因累計 10 次失敗自動退出；需要時請手動停止任務。
  • 若程式提示「許可權不足」，請以 管理員身份 執行程式。
