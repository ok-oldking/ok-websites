排軸序列

返回：文件索引 / README

用於控制技能釋放的優先順序順序。

格式說明

接受以下值；英文逗號 , 和中文逗號 ， 均可作為分隔符，欄位前後空白和空欄位會被清理：

1,2,3,4          # 干员战技
ult_1~ult_4      # 干员终结技
e                # 连携技能
sleep_[n]        # 等待 n 秒（如 sleep_1.5）
normal_[n]       # 临时进入普通战斗 n 秒

示例

ult_2,1,e,ult_1,sleep_1.5,ult_3

表示：

  • 優先嚐試幹員2的終結技
  • 然後嘗試幹員1的戰技
  • 再嘗試連攜技能
  • 嘗試幹員1的終結技
  • 等待1.5秒
  • 嘗試幹員3的終結技
  • 回到第一步(嘗試幹員2的終結技)

行為邏輯

  • 系統會按照順序迴圈嘗試技能，同時仍按「無數字操作間隔」週期鎖敵並向前閃避
  • 戰技、終結技和連攜技成功後推進到下一項並重置 5 秒計時
  • sleep_n 會阻塞等待 n 秒，完成後推進並重置計時；解析器接受任意浮點數，但負數傳給 time.sleep 會丟擲異常並結束本次自動戰鬥，因此實際必須大於等於 0
  • normal_n 臨時執行普通戰鬥 n 秒，n 必須大於 0；完成後恢復排軸並重置計時
  • 某個技能動作距上次成功達到 5 秒仍未成功時，本場戰鬥永久回退普通戰鬥，不再恢復排軸

使用場景

  • 控制爆發順序
  • 優先釋放關鍵技能
  • 配合連攜或特定戰術
  • 避免技能被錯誤消耗
  • sleep可配合伊馮之類的長時爆發幹員

解析與執行流程

flowchart TD
    A[读取排轴序列字符串] --> B[按英文逗号拆分]
    B --> C{动作是否合法}
    C -->|否| D[记录并忽略无效字段]
    C -->|是| E[生成动作列表]
    E --> F[战斗中依次执行]
    F --> G{动作类型}
    G -->|1-4| H[释放战技]
    G -->|ult_1-ult_4| I[释放终结技]
    G -->|e| J[释放连携技]
    G -->|sleep_n| K[等待 n 秒]
    G -->|normal_n| L[普通战斗 n 秒]
    H --> M{5 秒内成功}
    I --> M
    J --> M
    K --> F
    L --> F
    M -->|是| F
    M -->|否| N[回退普通战斗]

注意事項

  • 推薦使用英文逗號 ,；中文逗號也可解析
  • 順序非常重要
  • 不要填寫負數 sleep_n；雖然能通過解析，但執行時無效並會中斷本次自動戰鬥
  • 非法欄位會被忽略；若配置為空或過濾後沒有有效欄位，則回退預設序列 1,2,3
