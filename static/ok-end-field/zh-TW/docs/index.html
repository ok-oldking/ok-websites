ok-ef 文件

ok-ef 是面向《明日方舟：終末地》的 Windows 自動化工具。它通過截圖識別、OCR、系統音訊反饋和常規鍵鼠輸入與遊戲互動；不讀取遊戲記憶體，也不修改遊戲檔案。
