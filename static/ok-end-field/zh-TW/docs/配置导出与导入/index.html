配置匯出與匯入

返回：文件索引 / README

用於備份、恢復或在多臺裝置之間遷移應用配置。配置儲存在應用目錄的 configs 資料夾中，包括任務開關與引數、賬號配置與賬號任務覆蓋、共享戰鬥配置、視窗與裝置選擇等。

1. 入口位置

開啟應用的 Capture 頁，在 Debug 卡片的按鈕行中可以找到兩個按鈕：

  • 匯出配置
  • 匯入配置

2. 匯出配置

  1. 點選“匯出配置”。
  2. 應用會把 configs 目錄打包為一個 zip 檔案，儲存到系統的下載資料夾，檔名形如 ok-ef-config-20260907_010515.zip。
  3. 匯出完成後會提示“配置已匯出”，並自動在資源管理器中定位該檔案。

匯出的 zip 不包含日誌與截圖；configs/backup、configs/global_config_migration_backup 兩個備份目錄也不會被打包。

3. 匯入配置

支援兩種方式，效果相同：

  • 點選“匯入配置”按鈕，在檔案對話方塊中選擇 zip 檔案（預設從下載資料夾開始瀏覽）。
  • 直接把 zip 檔案拖入應用主視窗的任意位置；一次拖入多個 zip 時只會匯入第一個。

對 zip 內容的要求：壓縮包中至少要有一個 .json 配置檔案。以下三種打包形態都可以識別：

  1. 由“匯出配置”生成的 zip（條目在 configs/ 目錄下）。
  2. 配置檔案直接放在壓縮包根部。
  3. 配置檔案放在壓縮包中的單個目錄裡（匯入時該目錄會被剝離，條目直接落到 configs）。

匯入流程：

  1. 確認對話方塊中點選確認後，應用會暫停執行中的任務。
  2. 現有配置先備份到 configs/backup/import_backup_<时间戳>/，然後 configs 目錄被匯入內容覆蓋（上述兩個備份目錄會保留）。
  3. 匯入完成後會提示“匯入完成”，並詢問是否立即重啟。

4. 生效與回滾

  • 匯入只修改磁碟上的配置檔案，正在執行的程式仍使用記憶體中的舊配置；點選“立即重啟”或之後手動重啟應用後才會生效。
  • 需要手動回滾時，先關閉應用，刪除 configs 中除 backup 和 global_config_migration_backup 兩個目錄以外的所有內容，再把 configs/backup/import_backup_<时间戳>/ 中的備份檔案複製回 configs。也可以改為重新匯入此前匯出的 zip。
  • 建議在相同或相近版本的應用之間匯出匯入；版本差異較大時，個別配置項可能被重置為預設值。

5. 常見問題

  1. 匯入按鈕提示“壓縮包中未找到配置檔案”：zip 裡沒有 .json 檔案，或選中的不是配置壓縮包。
  2. 拖入 zip 後沒有反應：確認拖入的是 .zip 檔案；個別自帶拖放處理的輸入框（如程式碼編輯區）不會觸發匯入。
  3. 匯出按鈕提示“匯出失敗”：檢查 configs 目錄是否被其他程式佔用（例如已開啟的配置檔案），重試即可。
