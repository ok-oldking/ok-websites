自动送货

返回：文档索引 / README

概述

自动接取当前选择地区的委托，按照配置路径将货物送至对应接收者。正常模式下每个账号最多执行 3 轮接取与送货。该任务支持多账户执行和多账户独立配置；仅接取、仅送货或路径测试模式不进行多账号轮换。

配置、地区和目标来自 DeliveryTask.py 与 delivery_area.py。

选项和配置

目标券数

可选值来自 DELIVERY_TARGET_TICKET_NUM_OPTIONS，当前为 163000、159000、119000、79800、73100。

界面将其显示为目标券数优先级序列，默认 119000，并允许配置多个券数。接单循环按照列表顺序查找，命中前面的券数后不会再查找后续券数；前面的券数没有可接委托时，才会继续尝试下一项。

多账户模式

自动送货既可以作为独立任务运行，也可以作为日常任务中的 ⭐自动送货 子项运行。独立任务保留完整的多账号和测试入口；日常子项复用日常任务的账号循环，只执行完整送货流程。

  • 开启「多账户模式」后，任务会按「账号列表」逐个切换账号执行自动送货。
  • 开启「多账户独立配置」后，同一送货任务可按账号覆盖目标券数、地区切换等常规配置；滑索配置位于「全局配置 / 滑索配置」，跨任务共享，但也可在账号页为每个账号设置独立滑索覆盖。
  • 账号列表每行一个账号；兼容旧格式 账号, 密码，但密码字段会被忽略。账号切换使用游戏登录页「最近」列表，不输入密码。
  • 独立任务保留「选择测试对象」「仅接取」「仅送货」等调试选项；日常任务入口不显示这些选项。

地区切换

通过下拉框选择当前送货地区

切换后会使用该地区的：

  • 委托地点识别规则
  • 送货目标列表
  • 对应的送货点滑索配置（按地点匹配）

通向{地点}送货点

从委托地点前往对应送货点的滑索距离序列

送货滑索和淤积点滑索在全局滑索配置中通过分类下拉框分开显示。账号页选择「滑索配置」后，可以按账号覆盖其中任意路线。

决定从已接委托地点前往取货点的路径。配置键按「通向{地点}送货点」命名，每个送货地点一个键，武陵当前包含：

  • 「通向武陵城送货点」（武陵城）
  • 「通向试验园区送货点」（试验园区）

对应地点配置为空时，本轮送货直接失败，不会借用另一地点路线。

示例：

50,34

工作流程

flowchart TD
    A[启动自动送货] --> A1{多账户模式}
    A1 -->|是| A2[按账号列表进入当前账号上下文]
    A1 -->|否| B[使用当前账号配置]
    A2 --> B[读取账号覆盖后的地区切换与目标券数]
    B --> C{选择测试对象}
    C -->|指定测试| D[执行单段或完整循环测试]
    C -->|无| E{仅送货}
    E -->|是| H[识别当前委托目标]
    E -->|否| F[按目标券数接取委托]
    F --> G{仅接取}
    G -->|是| Z[结束]
    G -->|否| H
    H --> I[传送到任务区域]
    I --> J[按通向{地点}送货点滑索序列取货]
    J --> K[OCR 识别目标 NPC 或回收目标]
    K --> L[按目标滑索序列前往]
    L --> M[提交货物]
    M --> N{还有接取次数}
    N -->|是| F
    N -->|否| A3{还有下一个账号}
    A3 -->|是| A2
    A3 -->|否| Z
    D --> Z

功能选项

是否启用滚动放大视角

该配置已移动到「全局配置 / 滑索配置」，送货和刷体力任务共用同一项设置。

启用后，在对齐滑索时会自动滚动放大视角。

  • 可能提高对齐成功率
  • 也可能在某些情况下明显降低成功率

建议：

  • 启用时尽量使用宽大头发或深色头发(帽子)(别礼、赛希)
  • 避免使用黄白头发或帽子（识别可能受影响）

仅接取

前置：选择测试对象 =「无」

仅接取当前选择地区委托，不执行送货流程。

支持 7.31w、7.98w、11.9w、15.9w 和 16.3w，并按照配置列表从前到后确定接单优先级。

仅送货

前置：选择测试对象 =「无」，且已接取当前选择地区委托并处于可送货状态

启动自动识别并执行送货流程。

选择测试对象

用于调试或路径测试。

  • 默认：无（正常执行完整流程）

  • 可选：指定滑索分叉序列（用于单路径测试）

  • 完整循环测试：

    • 会依次测试每个送货目标的完整流程
    • 需要将任务锁定在送货点或其附近

发生异常时终止游戏

当脚本检测到异常情况时，自动关闭游戏和脚本，防止后续脚本其他任务卡死或游戏资源占用。

完成后退出

任务完成后自动执行：

  • 退出游戏
  • 关闭 App

补充说明

所有路径均为「滑索距离序列」，按顺序依次执行。

  • 当前仅配置「武陵」地区，默认地区也是武陵；无效地区值会回退到武陵。

  • 接单时会从委托文本缓存地点。武陵城在地图顶部搜索传送点，试验园区在地图右侧搜索；未识别地点或缺少该地点配置时，本轮送货失败，不会使用通用地图区域兜底。

  • 滑索推进阶段固定使用 E 键触发连接点（底层按键输入），不受通用热键配置影响。

  • 原因是该交互键在游戏内不可改绑，且高频重复输入可降低短距离滑索漏触发概率。
