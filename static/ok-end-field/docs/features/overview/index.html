功能概览

功能会随版本变化；请以应用中可见的任务和最新发布说明为准。

日常与资源

  • 日常任务：送礼、帝江号、地区建设、奖励领取、刷体力及演算等流程。
  • 刷体力：普通、高阶、危境和能量淤积点，支持战斗配置与排轴。
  • 运送委托接取：按券种和金额筛选并接取委托。
  • 自动送货：执行配置的委托接取与送货路径。
  • 仓库物品转移：跨仓库批量转移指定物品。

后台触发（不完全支持）

后台运行不完全支持：仅部分任务支持，涉及键盘操作的部分暂不支持。

  • 自动战斗：检测战斗状态后按普通、排轴或实时条件逻辑释放技能。
  • 自动交互：自动跳过剧情并执行地图传送交互。
  • 自动拾取：按白名单拾取，并根据黑名单过滤。
  • 物品导航与实时检测：通过官方地图或本地 WebSocket 位置数据导航，并提供 YOLO 调试能力。

配置与调度

  • 账号配置：多账号和账号独立的任务配置。
  • Windows 计划任务：定时启动已注册的一次性任务。
  • 鼠标转向标定：校准游戏内鼠标视角旋转系数。
