自动拾取（AutoPickTask）

返回：文档首页 / README

本文对应已实现触发任务 AutoPickTask，是面向开发者的实现状态说明，不作为正式用户入口。实现位于 src/tasks/trigger/AutoPickTask.py。

当前实现

  • 界面名称：自动拾取
  • 任务类型：触发式任务，注册在 src/config.py 的 trigger_tasks
  • 默认配置：_enabled = True
  • 运行条件：in_combat_world() 返回真，且屏幕出现 F 交互提示

白名单与黑名单

白名单来自 AutoPickTask.white_list：

采集, 萤壳虫, 打开, 荞花, 灰芦麦, 灼壳虫, 苦叶椒, 柱状菌, 酮化灌木, 柑实, 触碰, 激活, 芽针, 多齿叶, 砂叶

黑名单来自 AutoPickTask.black_list：

协议核心, 激活箱子

检测流程

flowchart TD
    A[触发任务轮询] --> B{是否大世界状态}
    B -->|否| Z[本轮结束]
    B -->|是| C{是否有 F 交互提示}
    C -->|否| Z
    C -->|是| D[OCR 读取提示文本]
    D --> E{命中黑名单}
    E -->|是| Z
    E -->|否| F{命中白名单}
    F -->|是| G[按交互键拾取]
    F -->|否| H[检测提示图标白色比例]
    H --> I{白色比例低于阈值}
    I -->|是| G
    I -->|否| Z
