Feature overview

Available functionality can change between releases. Refer to the task list in the application and the latest release notes for the current set.

Dailies and resources

  • One-click dailies for gifts, Dijiang, area construction, reward collection, farming, and calculation workflows.
  • Combat farming for normal, advanced, crisis, and energy-silt stages, including battle configurations and action sequences.
  • Delivery commission pickup, Auto Delivery, and warehouse item transfers.

Background triggers (partial support)

Background mode is only partially supported; keyboard-operated actions are not supported in the background.

  • Auto Combat releases skills using normal, action-sequence, or real-time conditional logic.
  • Auto Interaction skips dialogue and handles map-transfer interactions.
  • Auto Pickup uses allowlists and blocklists.
  • Item Navigation and Realtime Detection use official-map or local WebSocket position data and provide YOLO debugging tools.

Configuration and scheduling

  • Account configuration supports multi-account and account-specific task configuration.
  • Windows Task Scheduler can start registered one-time tasks on a schedule.
  • Mouse rotation calibration helps tune in-game camera rotation coefficients.
