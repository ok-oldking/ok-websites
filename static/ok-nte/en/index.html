FAQ

Recognition or clicks are unreliable

Check the following in order:

  1. The game uses a 16:9 resolution of at least 1920×1080.
  2. Brightness, UI opacity, and keybindings use the recommended settings.
  3. Graphics filters, sharpening, and overlays are disabled.
  4. The game window is not minimized and the system is not locked or asleep.
  5. The mouse is not interfering with a foreground game window.

Installation or startup fails

  • Use the latest installer and add the installation directory to your security software's trusted list if it blocks application files.
  • When running from source, run uv sync again to install project-compatible dependencies.

Bug reports and feedback

If the issue remains, open a GitHub Issue and include:

  • A clear screenshot or recording of the issue.
  • Relevant, redacted log files.
  • Steps to reproduce, actual behaviour, and expected behaviour.
  • The application version, Windows version, and whether the issue reproduces consistently.

Do not upload account details, personal paths, keys, or other sensitive information.
