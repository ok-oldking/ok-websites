快速上手

啟動任務

  1. 按照使用前配置檢查遊戲設定和視窗狀態。
  2. 啟動 ok-nte。
  3. 在遊戲中進入需要自動化的場景或關卡。
  4. 在應用介面選擇任務並點選“開始”。

任務開始後，請留意應用日誌和遊戲畫面。識別失敗時，先停止任務，確認畫面、解析度和按鍵設定後再重新開始。

命令列啟動

可用命令列引數在啟動後自動執行指定任務：

# 启动后执行列表中的第 2 个任务，并在完成后退出
ok-nte.exe -t 2 -e
  • -t 或 --task：啟動後自動執行任務列表中的第 N 個任務，1 表示第一個任務。
  • -e 或 --exit：任務完成後自動退出程式。

!!! warning 任務編號依賴當前應用的任務列表。使用命令列自動化前，先在介面中確認目標任務的位置。

停止與恢復

如果畫面與預期不一致、遊戲視窗失焦，或需要臨時接管操作，請立即在應用中停止任務。恢復前，重新確認場景、視窗和前置條件；不要依賴長時間的重複輸入來糾正異常畫面。
