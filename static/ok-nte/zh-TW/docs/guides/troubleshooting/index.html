常見問題與反饋

識別或點選不穩定

依次檢查：

  1. 解析度是否為 16:9 且至少 1920×1080。
  2. 遊戲亮度、UI 透明度和按鍵是否使用推薦設定。
  3. 是否關閉了顯示卡濾鏡、銳化和畫面懸浮層。
  4. 遊戲視窗是否沒有最小化，螢幕是否沒有鎖定或熄滅。
  5. 執行時滑鼠是否干擾了前臺遊戲視窗。

安裝或啟動失敗

  • 確認使用最新版安裝包，並將安裝目錄加入安全軟體信任列表（如安全軟體攔截了程式）。
  • 使用原始碼執行時，重新執行 uv sync 以安裝與專案匹配的依賴。
  • 不要在包含異常許可權限制的目錄中執行；必要時更換到普通使用者可寫的目錄。

聲音驅動無響應

確認遊戲有正常音訊輸出，並檢查應用中的音訊相關設定。聲音觸發僅讀取系統音訊輸出；當音訊裝置切換、靜音或沒有遊戲聲音時，功能無法觸發。

反饋問題

在 GitHub Issues 提交問題時，請提供：

  • 清晰的錯誤截圖或錄屏。
  • 已脫敏的相關日誌。
  • 復現步驟、實際結果和期望結果。
  • 使用的軟體版本、Windows 版本和是否穩定復現。

不要上傳賬號資訊、個人路徑、金鑰或其他敏感資料。
