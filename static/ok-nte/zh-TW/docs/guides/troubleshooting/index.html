常見問題

更新卡住怎麼辦？

如果 ok-nte 更新長時間沒有進度，通常是依賴下載速度過慢導致的。可以按以下方案處理：

  • 進入控制台右上角的設定，更換一個下載速度較快的 pip 映象源。
  • 進入控制台右上角的設定，更換為mirro醬更新源（需要 CD-KEY）。
  • 開啟跳板或代理後，改用官方 PyPI 源重新更新。
  • 解除安裝當前版本的 ok-nte，再通過官方渠道下載最新版本的安裝包（setup）並重新安裝。
識別或點選不穩定

依次檢查：

  1. 解析度是否為 16:9 且至少 1920×1080。
  2. 亮度、主介面透明度、攝像機和按鍵設定是否符合使用前配置中的要求。
  3. 是否關閉了顯示卡濾鏡、HDR、銳化和畫面懸浮層。
  4. 確認遊戲視窗未最小化，電腦未鎖屏，且螢幕保持亮起。
  5. 執行時滑鼠是否干擾了前臺遊戲視窗。
自動戰鬥識別不穩定？

請在遊戲設定的 控制 ➔ 系統功能 中關閉 傷害顯示。傷害數字會遮擋 UI，干擾自動戰鬥識別。

同時確認其他設定符合使用前配置中的要求。

安裝或啟動失敗
  • 確認使用最新版安裝包，並將安裝目錄加入安全軟體信任列表（如安全軟體攔截了程式）。
  • 使用原始碼執行時，重新執行 uv sync 以安裝與專案匹配的依賴。
  • 不要在包含異常許可權限制的目錄中執行；必要時更換到普通使用者可寫的目錄。
聲音觸發無響應

聲音觸發使用 Windows WASAPI 按程序迴環捕獲，直接讀取目標遊戲程序及其子程序的輸出音訊，不依賴系統預設輸出裝置。

如果沒有觸發，請檢查：

  • 遊戲程序已啟動，並且遊戲內確實有聲音輸出。
  • 應用中的聲音觸發功能已啟用，相關設定正確。
  • 當前 Windows 環境支援按程序迴環捕獲。

問題反饋

如果以上方法未能解決您的問題，歡迎通過 Issues 向我們反饋。為幫助我們快速定位問題，請在提交時提供以下資訊：

  • 問題截圖：清晰展示異常介面或錯誤提示。
  • 日誌檔案：附上程式目錄下的 .log 日誌檔案。
  • 詳細描述：您進行了哪些操作？問題具體表現是什麼？問題是穩定復現還是偶爾發生？
