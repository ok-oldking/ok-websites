使用前配置

[!IMPORTANT] 在啟動自動化前，請務必檢查並確認以下設定：

  • 圖形設定
    • 遊戲亮度：使用遊戲 預設亮度。
    • UI 設定：禁止 所有會導致 UI 與預設不同的設定
      • UI 透明度 須設為 1.0。
    • 顯示卡濾鏡：關閉 所有顯示卡濾鏡、HDR 和銳化效果（如 NVIDIA Freestyle, AMD FidelityFX）。
    • 顯示卡色彩 (AMD/A卡使用者)：顯示色彩需與預設 NVIDIA/N卡保持一致，以避免影像識別偏差。若因此導致識別失敗，可嘗試開啟 Windows 系統設定中的 “自動管理應用的顏色” (Auto Color Management)。
  • 解析度
    • 推薦使用 1920x1080 或以上 16:9 的主流解析度。
  • 按鍵設定
    • 請務必使用遊戲 預設 按鍵繫結。
  • 攝像機設定
    • 移動鏡頭修正：停用
    • 按下鎖定鏡頭回正：啟用
  • 第三方軟體
    • 關閉任何在遊戲畫面上顯示資訊的懸浮窗，如 MSI Afterburner (小飛機) 的 幀率顯示。

[!WARNING] 視窗與系統狀態注意事項

  • 滑鼠干擾：當遊戲視窗處於 前臺 時，請勿移動滑鼠，否則會干擾程式的模擬點選。
  • 視窗狀態：遊戲視窗可以置於後臺，但 不可最小化。
  • 系統狀態：請勿讓電腦 熄屏 或 鎖屏，否則將導致程式中斷。
