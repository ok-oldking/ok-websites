使用前配置

執行自動化前，請確認以下設定。它們直接影響畫面識別與輸入的穩定性。

遊戲畫面

  • 使用遊戲預設亮度。
  • 不要使用會改變預設介面的設定；UI 透明度應為 1.0。
  • 關閉 NVIDIA Freestyle、AMD FidelityFX 等顯示卡濾鏡和銳化效果。
  • AMD 顯示卡使用者應保證顯示色彩接近預設 NVIDIA 色彩；如有色彩識別問題，可嘗試啟用 Windows 的“自動管理應用的顏色”。
  • 使用 1920×1080 或更高的 16:9 解析度。
  • 關閉 MSI Afterburner 等在遊戲畫面上顯示幀率或其他資訊的懸浮層。

遊戲控制

  • 使用遊戲預設按鍵繫結。
  • 將“移動鏡頭修正”設為停用。
  • 將“按下鎖定鏡頭回正”設為啟用。

Windows 與視窗狀態

!!! warning 遊戲可位於後臺，但不能最小化。執行期間不要熄屏或鎖屏。

  • 當遊戲在前臺時，請不要移動滑鼠，以免干擾模擬點選。
  • 開始長時間任務前，先確認目標遊戲視窗處於可截圖、可接收輸入的狀態。
  • 若使用聲音驅動功能，請確認遊戲音訊輸出正常。
