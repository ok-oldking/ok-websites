功能概覽

功能會隨版本變化；請以應用內可見任務和最新發行說明為準。

日常與周常

  • 一鍵日常：經驗與甲硬幣、異能升級材料、弧盤突破材料、空幕、一咖舍任務、影院約會和羈遇贈禮。
  • 羈遇贈禮：自動完成角色贈禮流程。

都市閒趣

  • 自動釣魚和自動鼓組音遊。
  • 店長特供：迴圈進出關卡，需配合遊戲內的掛機流派。
  • 自動粉爪大劫案，以及快速拾取、自動切換角色快速奔跑等便利功能。

特定任務與副本

  • 九百九十九夜、異象界域、異象追獵和自動小旋風。
  • 唄果智慧體：在唄果社群中發帖、回帖、點贊，或使用助手模式輔助生成文案。

即時觸發與戰鬥

  • 自動戰鬥：基於計算機視覺，並可通過角色中心管理自定義出招表和識別特徵。
  • 聲音驅動：基於遊戲音訊反饋進行自動閃避和反擊。
  • 跳過對話與快速傳送。

娛樂與輔助

  • 自動彈琴：分析 MIDI 音軌並完成遊戲內鋼琴演奏。
