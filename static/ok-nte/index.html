常见问题

常见问题

更新卡住怎么办？

如果 ok-nte 更新长时间没有进度，通常是依赖下载速度过慢导致的。可以按以下方案处理：

  • 进入控制台右上角的设置，更换一个下载速度较快的 pip 镜像源。
  • 进入控制台右上角的设置，更换为mirro酱更新源（需要 CD-KEY）。
  • 开启跳板或代理后，改用官方 PyPI 源重新更新。
  • 卸载当前版本的 ok-nte，再通过官方渠道下载最新版本的安装包（setup）并重新安装。
识别或点击不稳定

依次检查：

  1. 分辨率是否为 16:9 且至少 1920×1080。
  2. 亮度、主界面透明度、摄像机和按键设置是否符合使用前配置中的要求。
  3. 是否关闭了显卡滤镜、HDR、锐化和画面悬浮层。
  4. 确认游戏窗口未最小化，电脑未锁屏，且屏幕保持亮起。
  5. 运行时鼠标是否干扰了前台游戏窗口。
自动战斗识别不稳定？

请在游戏设置的 控制 ➔ 系统功能 中关闭 伤害显示。伤害数字会遮挡 UI，干扰自动战斗识别。

同时确认其他设置符合使用前配置中的要求。

安装或启动失败
  • 确认使用最新版安装包，并将安装目录加入安全软件信任列表（如安全软件拦截了程序）。
  • 使用源码运行时，重新执行 uv sync 以安装与项目匹配的依赖。
  • 不要在包含异常权限限制的目录中运行；必要时更换到普通用户可写的目录。
声音触发无响应

声音触发使用 Windows WASAPI 按进程回环捕获，直接读取目标游戏进程及其子进程的输出音频，不依赖系统默认输出设备。

如果没有触发，请检查：

  • 游戏进程已启动，并且游戏内确实有声音输出。
  • 应用中的声音触发功能已启用，相关设置正确。
  • 当前 Windows 环境支持按进程回环捕获。
