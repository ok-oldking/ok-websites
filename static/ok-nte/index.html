常见问题

识别或点击不稳定

依次检查：

  1. 分辨率是否为 16:9 且至少 1920×1080。
  2. 游戏亮度、UI 透明度和按键是否使用推荐设置。
  3. 是否关闭了显卡滤镜、锐化和画面悬浮层。
  4. 游戏窗口是否没有最小化，屏幕是否没有锁定或熄灭。
  5. 运行时鼠标是否干扰了前台游戏窗口。

安装或启动失败

  • 确认使用最新版安装包，并将安装目录加入安全软件信任列表（如安全软件拦截了程序）。
  • 使用源码运行时，重新执行 uv sync 以安装与项目匹配的依赖。
  • 不要在包含异常权限限制的目录中运行；必要时更换到普通用户可写的目录。

声音驱动无响应

确认游戏有正常音频输出，并检查应用中的音频相关设置。声音触发仅读取系统音频输出；当音频设备切换、静音或没有游戏声音时，功能无法触发。
