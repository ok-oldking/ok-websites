使用前配置

运行自动化前，请确认以下设置。它们直接影响画面识别与输入的稳定性。

游戏画面

  • 使用游戏默认亮度。
  • 不要使用会改变默认界面的设置；UI 透明度应为 1.0。
  • 关闭 NVIDIA Freestyle、AMD FidelityFX 等显卡滤镜和锐化效果。
  • AMD 显卡用户应保证显示色彩接近默认 NVIDIA 色彩；如有色彩识别问题，可尝试启用 Windows 的“自动管理应用的颜色”。
  • 使用 1920×1080 或更高的 16:9 分辨率。
  • 关闭 MSI Afterburner 等在游戏画面上显示帧率或其他信息的悬浮层。

游戏控制

  • 使用游戏默认按键绑定。
  • 将“移动镜头修正”设为禁用。
  • 将“按下锁定镜头回正”设为启用。

Windows 与窗口状态

!!! warning 游戏可位于后台，但不能最小化。运行期间不要熄屏或锁屏。

  • 当游戏在前台时，请不要移动鼠标，以免干扰模拟点击。
  • 开始长时间任务前，先确认目标游戏窗口处于可截图、可接收输入的状态。
  • 若使用声音驱动功能，请确认游戏音频输出正常。
