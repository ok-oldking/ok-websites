🚀 启动任务

  1. 进入您想要自动化的关卡或场景。
  2. 在程序界面上点击 “开始” 按钮即可。

💻 命令行参数

您可以通过命令行参数实现自动化启动。

# 示例：启动后自动执行第二个任务（日常任务），并在任务完成后退出程序
ok-nte.exe -t 2 -e
  • -t 或 --task: 启动后自动执行第 N 个任务。1 代表任务列表中的第一个。
  • -e 或 --exit: 任务执行完毕后自动退出程序。
