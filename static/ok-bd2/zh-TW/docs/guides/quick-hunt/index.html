01 開始前準備

先用方案裡的「模擬執行預覽」確認米飯分配。 預覽只展示計劃，點選任務的「開始」才會實際執行。

從遊戲主頁開始，確保快速狩獵和目標關卡已經解鎖。狩獵場沿用遊戲當前選擇的關卡，執行前請先在遊戲裡選好。

點選圖片放大。當前版本通過「編輯刷取方案」安排米飯用途。

02 第一次怎麼執行

  1. 開啟「快速狩獵」的設定，點選「編輯刷取方案」。
  2. 選擇或調整方案，設定保留的免費米飯與執行步驟。
  3. 在「模擬執行預覽」裡選擇金幣、經驗是否雙倍及米飯數量，核對結果後儲存。
  4. 按需啟用聖石洞穴，設定聖石目標和火把分配。
  5. 返回遊戲主頁，點選任務旁的「開始」。

03 方案怎麼執行

規則按從上到下的順序匹配，只執行第一條滿足條件的規則；沒有匹配規則時執行預設步驟。

每條規則中的步驟按順序執行，可分配給狩獵場、金幣或經驗。單次消耗 6 米飯，不足一次的餘量保留；設定的免費米飯保留量也會生效。

方案可以複製、重新命名，並切換當前使用的方案。執行或排隊期間如需儲存變更，請先停止任務。

04 聖石與消耗

米飯方案與聖石洞穴分別配置。聖石洞穴會結合屬性庫存和所選策略處理火把，執行前請確認目標與分配方式。

程式會確認免費資源開關及消耗資訊；識別結果不明確時可能安全停止。請檢視執行狀態中的米飯、火把、當前階段和結果。

05 常見問題

為什麼沒有刷我想要的狩獵場？

指令碼沿用遊戲當前選擇的狩獵場。請先在遊戲裡選擇目標，再開始任務。

為什麼第二條規則沒有執行？

規則是按優先順序選擇，第一條匹配後不會再執行後續規則。需要連續刷取多個目標時，把它們加入同一條規則的步驟。

預覽和實際次數不同？

預覽使用手動填寫的雙倍狀態和米飯數量，實際執行使用遊戲識別結果，並遵守資源保留量。出現異常時保留現場並生成問題報告。
