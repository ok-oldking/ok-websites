ok-bd2

基於 ok-script 框架的 BrownDust II Windows PC 自動化輔助工具。

支援自動登入、日常任務、快速狩獵、PVP、跑商、裝備日常、任務領獎、主線探索和每週地圖採集，通過影像識別與滑鼠操作執行任務。

下載安裝包{ .md-button .md-button--primary } 安裝與完整使用說明{ .md-button }

開始使用

  1. 使用 Windows 10 / 11 和 BrownDust II PC 客戶端，將遊戲設定為 16:9、FHD 畫質。
  2. 下載 Releases 中的 setup.exe 安裝包，按 README 完成執行前檢查。
  3. 在程式中配置並執行任務；遇到異常時，使用“生成問題報告”保留現場。
