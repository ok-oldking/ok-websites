ok-bd2 釋出配置指南

這份配置只需要做一次。配置完成後，推送 v0.1.0 這類 tag，GitHub Actions 會自動生成 PyAppify 安裝包，並同步 ok-bd2-update 更新倉庫。

1. 建立 GitHub 更新倉庫

在 GitHub 建立一個新倉庫：

GodRaymond233/ok-bd2-update

建議保持空倉庫，不要勾選初始化 README、.gitignore 或 License。釋出流程會 自動把 deploy.txt 中列出的檔案同步進去。

2. 建立 CNB 更新倉庫

在 CNB 建立一個新倉庫：

GodRaymond233/ok-bd2-update

pyappify.yml 裡的 China 配置使用這個地址：

https://cnb.cool/GodRaymond233/ok-bd2-update.git

CNB 支援直接使用瀏覽器倉庫地址作為 Git 地址，也支援 .git 字尾格式。

3. 建立 GitHub token

在 GitHub 建立一個 Fine-grained personal access token，給它訪問 GodRaymond233/ok-bd2-update 的許可權。

推薦許可權：

Repository access: Only selected repositories -> GodRaymond233/ok-bd2-update
Contents: Read and write
Metadata: Read-only

生成後複製 token。這個 token 只會作為 GitHub Actions Secret 儲存，不要提交到 倉庫檔案裡。

4. 建立 CNB token

在 CNB 建立一個可以推送 GodRaymond233/ok-bd2-update 的訪問令牌。它要能通過 HTTPS Git 寫入倉庫。

5. 新增 GitHub Actions Secrets

開啟主倉庫：

https://github.com/GodRaymond233/ok-bd2

進入：

Settings -> Secrets and variables -> Actions -> New repository secret

新增兩個 Secret：

OK_GH   = 第 3 步创建的 GitHub token
CNB_GH  = 第 4 步创建的 CNB token

不用新增 GITHUB_TOKEN，GitHub Actions 會自動提供。

6. 確認倉庫配置

當前專案已經配置好這些檔案：

pyappify.yml
deploy.txt
.update_repo_gitignore
.github/workflows/build.yml

如果你以後改 GitHub 使用者名稱或倉庫名，需要同步修改：

pyappify.yml
.github/workflows/build.yml
src/config.py
README.md

7. 釋出

提交併推送主倉庫後，建立一個正式版本 tag：

git tag v0.1.0
git push origin v0.1.0

釋出完成後，Release 頁面應出現這些檔案：

ok-bd2-win32-China-setup-<版本>.exe
ok-bd2-win32-online-setup-<版本>.exe
ok-bd2-win32-Global-setup-<版本>.exe

安裝 ok-bd2-win32-China-setup-<版本>.exe 後，本機目錄會類似：

C:\Users\<你>\AppData\Local\ok-bd2

雙擊 ok-bd2.exe 時，先出現白色 PyAppify 更新視窗；更新完成後再出現黑色 ok-script 主介面。
