ok-kes

{ .hero-logo }

一個基於影像識別的《卡厄思夢境》自動化輔助工具，支援後臺執行。工具通過 Windows 介面模擬使用者操作，不讀取遊戲記憶體，也不修改遊戲檔案。

!!! warning "使用須知" 本專案開源、免費，僅供個人學習和交流。使用者需要自行了解並承擔使用第三方自動化工具的風險。

快速開始

  1. 前往 GitHub Releases 下載最新的 ok-kes-win32-portable-v*.exe，不要下載 Source Code。
  2. 以管理員身份執行程式。
  3. 國際服玩家在軟體左下角設定中將“遊戲語言”設為繁體中文。
  4. 根據使用場景啟用自動卡厄思模式、自動出擊模式或半自動劇情模式。

主要功能

自動卡厄思模式

  • 自動處理路線、事件、戰鬥、休息、商店和獎勵結算。
  • 按配置管理卡牌的獲取、移除、複製和閃光。
  • 支援裝備選擇、目標主戰員、面具卡牌和存檔相關流程。
  • 支援配置匯入、匯出及熱門配置。

自動出擊模式

  • 根據卡牌優先順序自動戰鬥和出牌。
  • 自動選擇主戰員、卡牌及路線節點。
  • 自動處理休息、商店、資源補充和獎勵結算。

半自動劇情模式

  • 自動推進對話和檢視事件。
  • 遇到戰鬥或卡厄思關卡時，可手動切換對應的自動模式。

使用要求

  • Windows 系統，遊戲使用 16:9 解析度。
  • 推薦 1920×1080，也支援 1600×900 和 1280×720。
  • 關閉顯示卡濾鏡、銳化和覆蓋在遊戲畫面上的監控資訊。
  • 卡厄思模式需要在遊戲內開啟自動戰鬥和自動劇情。
  • 自動戰鬥依賴快捷鍵識別，請在遊戲設定中顯示快捷鍵。

常見問題

工具無法識別遊戲畫面

確認遊戲語言配置正確，並關閉顯示卡濾鏡、HDR 強化、銳化和畫面覆蓋層。遊戲畫面需要保持受支援的 16:9 解析度。

程式檔案被攔截或刪除

將程式目錄新增到 Windows Defender 或其他防毒軟體的信任區，並重新下載完整程式。

如何分享配置

在模式配置頁使用“匯出配置”複製配置文本；其他使用者可通過“匯入配置”應用。也可以在開啟配置上傳後使用熱門配置功能。
