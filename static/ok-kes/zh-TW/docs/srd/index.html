ok-kes 軟體需求文件 (SRD)

1. 專案概述

ok-kes 是一個基於 ok-py 框架的《卡厄思夢境》遊戲自動化輔助工具。通過 OCR 識別遊戲畫面並模擬點選/按鍵操作，實現遊戲內各項功能的自動化。

1.1 專案定位

  • 目標使用者：卡厄思夢境玩家
  • 執行環境：Windows 11，Python 3.12，miniconda3/oknikke 環境
  • 框架依賴：ok-script（基於 PySide6 的 GUI 自動化框架）

1.2 技術棧

元件 技術選型
GUI 框架 ok-script (PySide6 + qfluentwidgets)
OCR onnxocr-ppocrv5
繁簡轉換 OpenCC
影像處理 OpenCV + OpenVINO
雲端儲存 Supabase (PostgreSQL + REST API)
版本控制 Git + GitHub

2. 功能模組

2.1 自動卡厄思模式 (ChaosMode)

檔案: ok_tasks/ChaosMode.py, ok_tasks/utils_chaos.py

2.1.1 功能概述

自動運行遊戲內卡厄思模式副本，處理戰鬥、路線選擇、卡牌操作等完整流程。

2.1.2 核心邏輯

每秒觸發一次 run() 方法：

  1. OCR 識別當前畫面文本，繁體轉簡體
  2. 依次嘗試約 50 個頁面處理函式（PAGE_HANDLERS 列表）
  3. 命中某一頁面則執行對應操作並結束本輪迴圈

2.2 自動出擊模式 (SortieMode)

檔案: ok_tasks/SortieMode.py, ok_tasks/utils_sortie.py

2.2.1 功能概述

自動運行遊戲內出擊模式副本，包括手牌識別與出牌、主戰員選擇等。

2.2.2 核心邏輯

與 ChaosMode 相同，使用 PAGE_HANDLERS 列表驅動頁面處理。

2.2.3 特色功能

手牌識別與出牌 (handle_battle_page):

  • OCR 識別手牌區域卡牌名
  • 按鍵識別（卡牌上的數字鍵位）
  • 出牌卡手檢測（連續 3 輪同一張牌未出掉則兜底出牌）
  • EP 能量檢測（滿能量時釋放 Ego 技能）
  • 幀卡住檢測與恢復

主戰員選擇 (handle_member_selection, handle_battle_member_config):

  • 按優先順序選擇主戰員
  • 支援拉黑列表（跳過指定角色）
  • 重新整理候選槽位
  • 出戰主戰員選擇（戰鬥前配置）

卡牌操作:

  • handle_battle_hand_select: 戰鬥中手牌選擇
  • handle_get_card: 獲得卡牌頁面按優先順序選擇
  • handle_draw_card_event: 抽牌事件選擇
  • handle_discard_hand_card: 丟棄手牌
  • handle_curiosity_activate: 尼婭的好奇心卡牌選擇
  • handle_extra_card_use: 額外使用卡牌

其他:

  • handle_boss_selection: 隨機選擇首領
  • handle_rest_sortie: 休息區閃光/休息選擇
  • handle_sortie_reward_settlement: 獎勵結算
  • handle_rational_supply, handle_ether_supply: 資源補充

2.3 配置同步與熱門配置

檔案: ok_tasks/config_sync.py, ok_tasks/config_io.py

2.3.1 上傳機制

  • 觸發方式: 模式執行時每 300 秒（5 分鐘）自動檢查上傳
  • 最低場數: 2 場（MIN_ROUNDS = 2，可配置）
  • 上傳內容: 配置 base64 + 勝率 + 版本號 + 遊戲語言 + 匿名使用者 hash
  • 不上傳: 個人身份資訊、遊戲賬號、截圖、IP 地址

2.3.2 匿名使用者標識

_get_user_hash(): 組合 MAC 地址 + 主機名 + 使用者名稱，取 SHA256 前 16 位。

2.3.3 雲端儲存 (Supabase)

欄位 型別 說明
id BIGINT 自增主鍵
mode TEXT "chaos" 或 "sortie"
config_b64 TEXT 配置的 base64 編碼
config_ver TEXT 版本號
game_lang TEXT 遊戲語言
win_rate REAL 勝率 (0.0~1.0)
total_rounds INTEGER 總戰鬥場數
user_hash TEXT 匿名使用者標識
created_at TIMESTAMPTZ 建立時間
updated_at TIMESTAMPTZ 更新時間

唯一約束: (user_hash, mode, config_b64) — 同一使用者同一配置只保留一條記錄

2.3.4 熱門配置展示

  • 排序方式：按平均勝率降序 / 按使用人數降序
  • 展示上限：20 條
  • 展示資訊：排名、勝率、使用人數、遊戲語言、版本

2.3.5 配置匯入匯出

  • _export_config_to_text(): 匯出為 base64 編碼
  • _import_config_from_text(): 從 base64 匯入（合併到當前配置）
  • 按鈕功能：所有配置操作在 UI 的 config 按鈕中完成

2.4 通用功能

2.4.1 多語言支援

  • 使用 OpenCC（繁轉簡）統一 OCR 文本處理
  • i18n 通過 .po / .mo 檔案實現 UI 翻譯
  • 全域性配置「遊戲語言」支援：簡體中文、繁體中文、日文、英文

2.4.2 卡牌識別增強（劍雨合併）

在 select_card 中，如果 OCR 將"劍雨"識別為分離的"劍"和"雨"兩個單字框，自動合併為一個 Box(name="剑雨")，刪除舊的單字框，使後續匹配能正確識別。

2.4.3 幀卡住檢測

is_frame_stuck(): 基於畫素變化檢測畫面是否卡住（連續 30 秒變化比例 < 0.5%），用于战斗恢复和日志输出。

3. 架构设计

3.1 整体架构

main.py (入口)
  └── ok.OK(config) ──→ GUI 启动
        ├── ChaosMode (TriggerTask)
        │     └── run() → 遍历 utils_chaos.PAGE_HANDLERS
        ├── SortieMode (TriggerTask)
        │     └── run() → 遍历 utils_sortie.PAGE_HANDLERS
        └── 全局配置 (Settings)
              ├── 游戏语言
              └── 配置上传开关

3.2 任务调度

  • 继承 ok.TriggerTask，每秒触发一次 run()
  • 每帧 OCR → 繁转简 → 依次尝试页面处理函数 → 命中即返回
  • 帧末尾检查是否需要上传配置

3.3 互斥机制

  • 开启 ChaosMode 时自动禁用 SortieMode
  • 开启 SortieMode 时自动禁用 ChaosMode

3.4 数据流

用户操作配置 → 保存到 configs/ 目录 JSON 文件
      ↓
每 5 分钟 → 读取配置 → base64 编码 → 上传到 Supabase
      ↓
热门配置按钮 → 从 Supabase 获取 → 聚合计算 → 展示列表 → 用户选择 → 导入配置
