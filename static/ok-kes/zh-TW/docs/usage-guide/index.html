ok-kes 使用說明

本文介紹 ok-kes 的下載安裝、介面操作、遊戲設定，以及卡厄思模式和出擊模式的配置方法。

下載安裝

  1. 下載軟體。本軟體支援自動更新，下載舊版本後，啟動時會自動更新到最新版本。下載方式：GitHub、Mirror醬、夸克網盤。
  2. 將工具安裝到全英文目錄。

軟體介面介紹

  • 啟動遊戲並以視窗模式執行；在選擇視窗區選擇遊戲視窗；互動方式選擇 PostMessage，然後點選開始。
  • 匯出日誌可以匯出工具執行日誌。如果遇到 Bug，請將日誌匯出後在 QQ 交流群中 @群主。
  • 工具左下角設定內可以選擇 OCR 後端。預設選擇“自動”：記憶體大於等於 12 GB 時使用 OpenVINO，小於 12 GB 時使用 ONNX Runtime。OpenVINO 會佔用更多記憶體，約 6～8 GB；ONNX Runtime 記憶體佔用較小，約 1～2 GB，但 CPU 佔用更高。

功能介面介紹

  • 本工具包含三個功能：自動卡厄思模式（賽季卡厄思、零式系統、卡厄思具象）、自動出擊模式和半自動劇情模式。
  • 請分別進入對應模式的介面後再開啟功能。可以在包含“進入”按鈕的介面開啟，也可以進入對應模式後開啟。在遊戲主頁面開啟功能將無效並自動關閉按鈕，防止指令碼意外點選。

  • 半自動劇情模式需要在上圖所示的介面開啟。遇到戰鬥關卡時，需要手動點選配隊人選，否則會卡在選人介面（不必關閉功能）；遇到卡厄思關卡時，需要手動開啟“自動卡厄思模式”。

遊戲設定

  • PC 端出擊模式的自動戰鬥依賴按鍵識別。請按照上圖進入遊戲設定，將快捷鍵顯示設定為 ON，這會明顯提高出牌準確率和戰鬥勝率。

  • 進入遊戲後，在遊戲內右上角手動開啟自動對話。

  • 使用 MuMu 模擬器時，請手動刪除手牌區的數字對映，如上圖所示。

配置介紹

卡厄思模式配置介紹

!!! note "國服與國際服配置說明"

國服和國際服的翻譯不同，不同戰員的配置無法通用。國際服在修改對應國服配置時，無需將簡體改成繁體（簡繁均可）。例如，國服卡牌【劍雨】對應國際服卡牌【劍之雨】，填寫國際服配置時可以寫【劍之雨】或者【劍之雨】，但不能直接寫【劍雨】。
  • 配置操作：工具支援匯入配置碼、匯出配置碼、熱門配置、儲存配置和切換配置。熱門配置由使用本工具的使用者自動上傳。如果不願意上傳任何資訊，可以在工具設定內關閉上傳功能；關閉後將無法使用熱門配置功能。
  • 遊戲語言：國服對應簡體中文，國際服對應繁體中文。
  • 刷存檔主戰員：只能填寫一名主戰員。後續的裝備分配、卡牌複製、閃光、移除等功能預設優先該主戰員。卡厄思模式不支援自動選擇配隊，需要手動配隊，填寫的名字應為三名主戰員之一。

  • 儲存資料儲存上限大於多少：對應下圖的資料價值層級；如果不滿足要求，會自動重新整理。
賽季卡厄思 零式系統
  • 保留大於多少TB的存檔：低於該配置值的存檔會自動回收為金幣。
  • 領取獎勵（只使用驗證卡）：如果想使用體力領取獎勵，需要手動將體力轉為驗證卡。驗證卡不足時，會自動關閉該功能，然後繼續刷卡厄思。
  • 任務優先順序：對應下圖的選項卡內容。可以填寫標題和內容中的任意部分欄位，但所有欄位必須符合原文順序，標題和內容之間不要新增任何符號。填寫關鍵欄位即可；寫得太完整，反而可能因為 OCR 漏識別文字而匹配不上。

例如上圖，如果僅配置【移除】，那麼能匹配第一個和第三個選項。按照從左到右的優先順序，會優先選擇第一個選項。如果想優先選擇第三個選項，可以配置成【“移除2張”，“移除”】。

再舉一個容易犯錯的例子：如上圖所示，如果配置【隨機獲得1張慾望卡牌】，那麼會優先匹配第一個選項，而不是第二個選項。因為【隨機獲得1張慾望卡牌】是【隨機獲得1張慾望：控制卡牌】這段文字的子序列，所以第一個選項也算“命中”。如果想命中第二個選項，應該填寫第一個選項中沒有的文字。這時可以考慮加入標題，配置成【裹挾慾望卡牌】。其中“裹挾”是標題，“慾望卡牌”是描述，能夠精準命中第二個選項。

  • 拉黑任務：有些任務選項可能會無限重複，例如某些增加壓力的事件；拉黑的選項不會被選擇。
  • 閃光優先順序：配置卡牌發生閃光時的選擇優先順序。對應出現如下介面時，決定優先選擇哪張卡牌。描述寫成“卡牌名 + 卡牌描述”，不需要填寫完整內容，只要欄位能正確區分卡牌即可。寫得太完整，反而可能因為 OCR 漏識別文字而匹配不上。建議不要填寫符號，例如【劍雨傷害次數增加】已經能精準匹配第三張閃光。注意：當前文字識別容易漏掉“一”字，遇到時儘量不要填寫，例如將“一縷光芒”寫成“縷光芒”。

  • 移除卡牌列表：在牌庫中刪牌時的優先順序，建議填寫完整卡牌名。
  • 閃光卡牌列表：在牌庫中選擇卡牌閃光時的優先順序，建議填寫完整卡牌名。
  • 複製卡牌列表：在牌庫中選擇卡牌複製時的優先順序，建議填寫完整卡牌名。
  • 需要冥想的卡牌：填寫需要通過冥想重新獲取閃光的卡牌，建議填寫完整卡牌名。當列表中的卡牌沒有獲得“閃光優先順序”指定的閃光時，工具會記錄該卡牌需要冥想，並在後續休息區嘗試選擇冥想。
  • 多少信用點以上冥想：只有當前信用點同時大於該配置值和本次冥想費用時，才會選擇冥想。如果休息和冥想都可以選擇，當前生命值低於 50% 時優先休息，否則選擇冥想。
  • 商店重新整理信用點閾值：德朗商店的免費重新整理次數用完後，僅當信用點大於該值且足夠支付本次重新整理價格時，才會消耗信用點付費重新整理。
  • 裝備1-3號位優先順序：按照優先順序列表替換裝備。未配置的傳說裝備無法替換配置中的普通裝備；配置中的普通裝備會替換未配置的傳說裝備；遇到未配置的裝備時，高品質裝備會替換低品質裝備。
  • 卡牌獎勵優先順序：中立卡牌、慾望卡牌的優先順序，例如夢之邊境、裝備包等。未配置的中立卡牌會跳過選擇。
  • 首層刷特定閃光：預設刷“閃光優先順序”中的第一張，可刷神閃；第一層沒有刷出時會自動逃脫並重新刷。例如想刷小丑“惡魔骰子”的減一費神閃，可以將“閃光優先順序”的第一個配置為【惡魔骰子此卡費用減少】。
  • 刷空檔：用於給某個戰員刷空檔，參考配置見娜迦空檔配置。開啟此功能時，請保證“刷初始卡牌”配置為空。
  • 優先使用金幣治療：開啟後使用金幣治療崩潰角色；關閉後會優先使用旅行券治療。
  • 治療崩潰：角色崩潰後是否前往創傷中心治療。
  • 優先移除基礎牌：如果“移除卡牌列表”中的卡牌都刪完了，會優先刪除主戰員的基礎牌；否則會跳過刪牌。
  • 進入商店：是否進入商店刪牌、購買商品。
  • 指定面具卡牌：用於幻想劇場地圖中的面具卡牌選擇。填寫時不需要完整卡牌描述，只需填寫能區分不同卡牌的關鍵欄位。
  • 面具卡牌刻印：選擇面具卡牌的刻印。填寫想刷的刻印的部分描述即可，目前僅支援刷一種刻印。
  • 刷初始卡牌：配置卡牌名字後，會在進入卡厄思的第一個事件中反覆重新整理“傳說卡牌3選1”選項，直到刷到配置的卡牌，例如“夢之邊境”。
  • 只打第一層：刷材料時可以開啟，提高刷卡厄思材料的效率。
  • 路線優先順序：一般不需要修改。工具會根據配置順序選擇事件最多或休息最多的路線；如果主要刷材料，也可以自行調整，例如將精英節點提前。
  • 幾輪後停止（0為不停止）：設定刷幾輪卡厄思。
  • 第幾層boss前自動暫停：在 Boss 前自動暫停，一般用不到。

出擊模式配置介紹

  • 配置操作：工具支援匯入配置碼、匯出配置碼、熱門配置、儲存配置和切換配置。熱門配置由使用本工具的使用者自動上傳。如果不願意上傳任何資訊，可以在工具設定內關閉上傳功能；關閉後將無法使用熱門配置功能。
  • 遊戲語言：國服對應簡體中文，國際服對應繁體中文。
  • 出戰主戰員優先順序：選擇由誰帶隊出擊。一般只填寫一名主戰員，但由於 OCR 可能不準確，也可以填寫多個名字。例如，“九”可能被識別成“力”，配置時可以填寫【“九”，“力”】。
  • 戰員優先順序：隊友的優先順序，可以填寫多個；採用嚴格匹配，請填寫完整名字。
  • 領取獎勵：開啟後會自動消耗腦子領取出擊獎勵；腦子消耗完後，會自動消耗體力領取獎勵；體力消耗完後，會自動關閉按鈕並繼續刷出擊模式。
  • 出牌優先順序：自動戰鬥的出牌優先順序。
  • 獲得卡牌優先順序：戰鬥後獲卡事件中的卡牌選擇優先順序。如果沒有命中配置中的卡牌，會跳過選擇。
  • 移除卡牌列表：在牌庫中刪牌時的優先順序，建議填寫完整卡牌名。
  • 閃光卡牌列表：在牌庫中選擇卡牌閃光時的優先順序，建議填寫完整卡牌名。
  • 複製卡牌列表：在牌庫中選擇卡牌複製時的優先順序，建議填寫完整卡牌名。
  • 裝備1-3號位優先順序：按照優先順序列表替換裝備。未配置的傳說裝備無法替換配置中的普通裝備；配置中的普通裝備會替換未配置的傳說裝備；遇到未配置的裝備時，高品質裝備會替換低品質裝備。
  • 只打第一層：預設開啟，打完第一層 Boss、領取獎勵後自動逃脫。
  • 進入商店：是否進入商店刪牌、購買商品。
  • 商店重新整理信用點閾值：德朗商店的免費重新整理次數用完後，僅當信用點大於該值且足夠支付本次重新整理價格時，才會消耗信用點付費重新整理。
  • 優先移除基礎牌：如果“移除卡牌列表”中的卡牌都刪完了，會優先刪除主戰員的基礎牌；否則會跳過刪牌。
  • 幾輪後停止（0為不停止）：設定刷幾輪出擊。
  • 卡牌獎勵優先順序：遇到中立卡牌選擇事件時的優先順序；沒有命中則跳過。
  • 丟棄卡牌優先順序：戰鬥中觸發棄牌事件時的優先順序，例如慢板等。
  • 任務優先順序：事件選項優先順序。可以填寫標題和內容中的任意部分欄位，但所有欄位必須符合原文順序，標題和內容之間不要新增符號。填寫關鍵欄位即可；寫得太完整，反而可能因為 OCR 漏識別文字而匹配不上。
  • 拉黑任務：出擊模式對勝率要求較高，一般會拉黑“咒術卡牌”“壓力增加”等選項。
  • 拉黑主戰員：需要拉黑的隊友。由於適配問題，可能存在部分戰員的卡牌功能未適配，或者部分隊友失敗率較高，可以選擇拉黑。
  • 生命值大於多少優先閃光（百分比）：休息區可以選擇閃光或休息，工具會根據血量百分比調整選擇。
  • 路線優先順序：一般不需要修改，工具會自動規劃最優路線。
  • 第幾層boss前自動暫停：一般用不到。可以在 Boss 前暫停並手動接管，以提高 Boss 戰勝率。
