ok-script-app

English

ok-script-app 是一個基於 ok-script 的 Python 自動化專案模板，適用於 Windows 原生遊戲、Android 模擬器和瀏覽器遊戲。

這個倉庫不是某個具體遊戲的自動化成品。它提供可直接執行的 GUI、任務與配置控制元件示例、OCR、模板匹配、測試、i18n、EXE 打包和更新發布配置。

從這裡開始

  1. 按照快速開始從模板建立並初始化倉庫。
  2. 在應用配置中選擇至少一種執行目標。
  3. 根據任務開發建立並註冊第一個任務。
  4. 使用打包與釋出中的流程生成 EXE。

主要內容

  • MyOneTimeTask 和 MyTriggerTask 任務示例。
  • 下拉框、布林值、數值、文本、列表、多選、檔案選擇、全域性配置和按鈕組等配置控制元件。
  • OCR、相對區域識別和模板匹配示例。
  • ConfigOption 全域性配置和 TaskTestCase 自動化測試示例。
  • gettext i18n 翻譯檔案和編譯產物。
  • PyAppify 和 GitHub Actions 打包釋出配置。
