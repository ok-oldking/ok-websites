最短上手路线

  1. 安装 Python 3.12（框架最低支持 Python 3.11）。
  2. 使用 ok-script-app 模板创建仓库。
  3. 按照快速开始配置 Windows 游戏或 ADB 设备。
  4. 运行调试模式并完成截图测试。
  5. 参考 API 文档实现自己的任务。
