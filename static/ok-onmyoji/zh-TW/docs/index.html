ok-Onmyoji

基於 ok-script 開發的《陰陽師》自動化工具。

支援多開、一鍵多工、定時任務以及多種日常與戰鬥任務，支援後臺執行。

主要功能

  • 多開與一鍵多工
  • 定時任務
  • 魂土、困二八、覺醒
  • 活動爬塔
  • 每日簽到、式神委派、寄養
  • 個人突破、寮突破等日常任務

使用說明

軟體通過影像識別及 Windows 使用者介面與遊戲進行互動，不讀取遊戲記憶體，不修改遊戲檔案。

推薦使用 MuMu 模擬器，並使用 ADB 截圖以支援後臺執行。
