Open source · Python · MCP · Vibe coding

Make a wish.Get a deployable automation app.

Describe the automation in Codex, Claude Code, or any coding agent with MCP. Through MCP, the agent observes your Windows application, game, or Android device, writes Python tasks, runs them against the real target, and fixes what fails. ok-script packages the result with a desktop GUI into a standalone Windows installer.

Observe the real target

Over MCP, the agent screenshots the configured window or ADB device and sees exactly what the task will see.

▶

Run and verify

run_task restores and verifies the starting state, then runs the task, saving logs, status, and screenshots for every attempt.

↻

Repair with hot reload

list_tasks finds the task source; reload_tasks swaps in the fix inside the running process without a restart.

↗

Ship a standalone app

Package the tasks and desktop GUI as a Windows installer that runs without an agent or LLM calls.
